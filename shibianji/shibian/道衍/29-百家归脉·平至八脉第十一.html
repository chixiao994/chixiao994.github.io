平至八脉

—— 至人启蒙八科，平人进阶八阶

序

天地生人，禀赋不齐。有生而筋骨异者，有幼而神明早慧者，有嗜一技如性命者，有闻大道而涕下者。此非病，乃异禀。

然异禀者，以平人常衡之，满目皆“过”与“不及”。过者，世谓之狂；不及者，世谓之痴。狂痴之目，久则真狂真痴矣。此非天夺其才，乃人废其常。

今立《平至八脉》，非以平人矩矱绳异禀，乃为异禀者铺可登之阶，为平人者开可入之门。八脉并列，日课可执，归改有径。

平人由此起修，至人由此成身。此华夏薪火之传，亦医道未垦之疆。

丙午春日 与为谨识

卷一·隐脉——文之阶

宗旨：知文之脉，会言之雅，继绝存亡，守默全真。

适用：文化修养之基，心性修炼之始。

入门三课：

  • 日诵五言：《千家诗》选七十二首，分四时节气。每日，三分钟。三月，语顺、气舒、情畅。
  • 暮录一字：抄《千字文》，日录一字，释其形音义。每日，五分钟。一年，识字三百、手熟于书。
  • 月读一传：《史记》《汉书》列传选，每月一人。每月。一年，知人、知世、知兴替。

进阶三阶：

  • 初阶：日诵不辍，识字满六百 → 可读《幼学琼林》《龙文鞭影》
  • 中阶：能作尺牍、能记家乘 → 文言始此
  • 高阶：能授一人日诵五言 → 传灯始此

归改：务虚辞者，停诵、入事科行一事；废文轻道者，从日诵起，不求解、不务深。

卷二·丹脉——身之阶（内丹服气）

宗旨：炼形化气，服气咽津，固本培元。

适用：养生修炼之基，精气神内养。

入门三课：

  • 晨起服气：面东，吐故纳新，咽津三十六次。每日，五分钟。三月，气满不思食。
  • 暮寝存想：意守丹田，内视五脏。每日，十分钟。三月，精神内守。
  • 月习辟谷（一日）：减食至平日之半，服气为资。每月一日。一年，肠胃清净。

进阶三阶：

  • 初阶：服气存想不辍 → 可入丹脉，习《参同契》启蒙
  • 中阶：能行小周天，气通任督 → 内丹始此
  • 高阶：能授一人晨起服气 → 传灯始此

归改：强闭致壅者，减意守，加导引；辟谷成怯者，复食、入事科。

卷三·经脉——医之阶（经络针灸）

宗旨：知经气之行，会腧穴之用，通调致和。

适用：医修之基，自我保健之要。

入门三课：

  • 晨起摩穴：按揉合谷、内关、足三里各三十六次。每日，三分钟。三十日，气血和、精神爽。
  • 暮识一经：循经识穴，每月一经，十二经周而复始。每日，五分钟。一年，经络分明。
  • 月灸一穴：选一保健穴，艾灸三五壮。每月。一年，正气存内。

进阶三阶：

  • 初阶：十二经熟识 → 可入经脉，习《灵枢》启蒙
  • 中阶：能自针合谷、足三里 → 自治始此
  • 高阶：能授一人晨起摩穴 → 传灯始此

归改：重通轻养者，节针简砭，归养气血；废药废灸者，兼学药食。

卷四·数脉——数之阶

宗旨：知象之征，会数之理，见几而作。

适用：数修之基，事修之辅，人人应世之智。

入门三课：

  • 日晷测影：立竿三尺，午正测影，分至必记。每日午正，一分钟。三月，知时知位。
  • 夜观星象：识北斗、北极、二十八宿方位。每月朔望，一刻钟。一年，知天知序。
  • 紫微十四主星识名：十四主星逐月习之。每旬一星。一年，识星十四。

进阶三阶：

  • 初阶：日晷无间、主星识全 → 可入数脉，习《皇极经世》启蒙
  • 中阶：能推二十四节气日影长短 → 知几始此
  • 高阶：能授一人识北斗、测日影 → 传灯始此

归改：锢数自缚者，停课、入事科行一事；务虚废事者，从日晷起，不推命、不射覆。

卷五·艺脉——艺之阶

宗旨：知器之用，会手之巧，游心寓形。

适用：艺修之基，人人养志之方。

入门三课：

  • 研墨三合：墨条、砚台、清水，研至浓淡适中。每日，三分钟。三十日，手稳、心定、神聚。
  • 日课一字：临帖九字，不贪多、不求似。每日，一刻钟。三月，腕有力、眼有准。
  • 月成一器：一纸、一绳、一木、一陶，成即弃之不吝。每月。一年，手巧、心旷。

进阶三阶：

  • 初阶：研墨不辍、月成一器 → 可入艺脉，择一专修（琴/棋/书/画/茶/香/园）
  • 中阶：能以器达意，不以技炫人 → 游艺始此
  • 高阶：能授一人研墨、临帖 → 传灯始此

归改：玩物丧志者，停器、入事科行一善；匠气锢心者，从研墨起，不求工、不求似。

卷六·动脉——武之阶

宗旨：知战之慎，会技之精，以战养勇。

适用：体修之辅，动脉之基，人人护身之能。

入门三课：

  • 拳经三势：《纪效新书》拳经三十二势选三：懒扎衣、金鸡独立、探马。每日，一刻钟。三月，步稳、拳顺、气不浮。
  • 木剑十式：劈、刺、点、崩、撩、拦、拿、滑、洗、压。每日，一刻钟。三月，腕活、眼准、身应。
  • 战日省三问：今日战气平否？有伤未愈否？战罢有养否？每战。不偏战、不逞勇。

进阶三阶：

  • 初阶：拳经三势精熟，木剑十式不断 → 可入动脉，习五禽、易筋
  • 中阶：能战而知止，胜而不骄 → 武德始此
  • 高阶：能授一人拳经三势 → 传灯始此

归改：以战为命者，停武、入医科自问六纲、入隐科守一；破而不立者，减战、加养、入身科习八段锦。

卷七·医脉——医之深阶

宗旨：知病之苦，会药之性，愈人愈己。

适用：医修之要，人人自护之常，从经脉进阶。

入门三课：

  • 晨起六纲自问：眠得一夜？食知味否？口知渴否？二便调否？手足温否？经带准否（女）/晨勃有无（男）？每日，一分钟。三十日，自知身之常变。
  • 暮寝摩腹百匝：掌心搓热，绕脐摩腹，左旋三十六，右旋三十六。每夜。三十日，脾胃和、夜溺减。
  • 药性韵读四味：四气（寒热温凉）、五味（酸苦甘辛咸）、入脏、主治。每旬一味，循环不辍。一年，识药四十八味。

进阶三阶：

  • 初阶：六纲日日不断，药性读满二十四味 → 可入经脉，习针灸要穴
  • 中阶：能为一家人辨六纲、调食饮 → 家医始此
  • 高阶：能授一人晨起六纲自问 → 传灯始此

归改：过虑己疾者，减问、移心、入艺科游艺；轻身废己者，从初阶起，己身未愈，不治他人。

卷八·事脉——事之阶

宗旨：知世之理，会人之情，成务立身。

适用：事修之基，人人应世之德。

入门三课：

  • 日行一善：扶倾、指路、让座、拾遗、开井、施茶、赠言。每日。三月，心开、人亲、事顺。
  • 暮省三过：今日有妄言否？有惰行否？有怨心否？每日，三分钟。三月，自明、自牧、自新。
  • 月济一人：非财物，乃时间、心力、一技。每月。一年，知人苦、知己能。

进阶三阶：

  • 初阶：日行一善、暮省三过 → 可入事脉，读《盐铁论》《新语》选
  • 中阶：能任一事、成一务 → 应世始此
  • 高阶：能授一人日行一善 → 传灯始此

归改：溺事忘返者，停行、入隐科守一、入艺科游心；以善为市者，从暮省起，不求名、不录报。

卷九·八脉通义

八脉非八途，乃一人之八面。

  • 隐脉养其心，丹脉固其本，经脉通其气，数脉明其几，艺脉游其巧，动脉强其身，医脉愈其疾，事脉成其业。
  • 体修之子，从动脉入，十年后兼医脉、艺脉、事脉，是大成。
  • 法修之子，从丹脉入，十年后兼经脉、数脉、医脉，是大成。
  • 术修之子，从数脉入，十年后兼艺脉、医脉、事脉，是大成。
  • 医修之子，从医脉入，十年后兼经脉、丹脉、事脉，是大成。
  • 文修之子，从隐脉入，十年后兼艺脉、事脉、医脉，是大成。
  • 艺修之子，从艺脉入，十年后兼隐脉、事脉、医脉，是大成。
  • 事修之子，从事脉入，十年后兼隐脉、数脉、医脉，是大成。

平人者，不知己之异禀，则从隐脉入，日诵五言、暮录一字；三年后八脉遍尝，自见其脉。

异禀者，幼见其偏，不必抑之；择一脉入，深耕三年，待其本立，乃开他门。

八脉皆日课，不废平人生业。日课三式，不过一刻；暮省六问，不过三息；月成一器，不夺三休。人人可执，日日可续，终身可行。
