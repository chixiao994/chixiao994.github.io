丹脉者，炼形化气之脉也。

丹非金石草木之谓，乃性命双修、形神俱妙之谓也。丹者，取其圆成之义；道者，取其自然之理。丹脉之学，以人身为鼎器，以精气为药物，以神火为功夫，以还元为归旨。

一、宗祖源流

上古渊源

  • 黄帝：访广成子于崆峒，得“至道之精，窈窈冥冥”之旨，为丹道之祖。后世《阴符经》托名黄帝，实丹家心法。
  • 王乔：周灵王太子，喜吹笙作凤鸣，浮丘公接上嵩山，三十余年仙去，为丹道成真之始。

三代传灯

  • 老子：著《道德经》，开“载营魄抱一”、“专气致柔”之旨，为内丹之祖。关尹子请老子著书，实丹经之始。
  • 尹喜：关令尹，得老子真传，著《关尹子》，以“纯气之守”为宗，开守中一脉。

秦汉之际

  • 魏伯阳：会稽上虞人，著《周易参同契》，假借爻象以论作丹，为丹经之祖。其书“词韵皆古，奥雅难通”，后世注者百家，皆宗之。
  • 河上公：汉文帝时人，结草为庵，注《老子》，以“虚心实腹”为要，开丹法简易之门。

魏晋南北朝

  • 葛玄：字孝先，丹阳句容人，从左慈得丹经，炼九鼎神丹，为灵宝派始祖。
  • 葛洪：字稚川，号抱朴子，葛玄从孙，著《抱朴子内外篇》，集外丹之大成。其《神仙传》载古仙事迹，为丹道立传。
  • 魏华存：女，字贤安，任城人，著《黄庭经》，开存思守一之旨，为上清派始祖。

隋唐五代

  • 苏元朗：隋代罗浮山道士，著《旨道篇》，开内丹“性命双修”之说。
  • 孙思邈：京兆华原人，著《千金方》兼通医药，晚年修丹，著《丹经》以传世，开医丹合一之脉。
  • 司马承祯：字子微，河内温人，著《坐忘论》《天隐子》，融丹道于隐修。
  • 吕洞宾：河中永乐人，得钟离权丹法，开钟吕金丹派。其诗词传世，丹道始入文人之心。

宋明

  • 陈抟：字图南，号扶摇子，亳州真源人，著《指玄篇》，传《无极图》，开宋代内丹之先。邵雍、周敦颐皆得其传。
  • 张伯端：字平叔，号紫阳，天台人，著《悟真篇》，以诗词论内丹，开南宗一脉。
  • 王重阳：原名中孚，字允卿，咸阳人，遇异人传道，开全真道，立北宗一脉。其徒丘处机、刘处玄、郝大通等，各立支派。
  • 张三丰：辽东懿州人，隐武当山，开三丰派，以武入丹，以丹运武，开动脉与丹脉交汇之先。

二、功法要义

内丹三要

内丹之学，以“鼎炉、药物、火候”为三要。

  • 鼎炉：以身为鼎，以心为炉。上丹田为鼎，下丹田为炉。鼎炉之位，定丹道之基。
  • 药物：以精气为药，以神为用。精为基础，气为动力，神为主宰。炼精化气，炼气化神，炼神还虚。
  • 火候：以呼吸为火，以意念为候。进阳火，退阴符，子午抽添，卯酉沐浴。火候之妙，存乎一心。

内丹四阶

  • 筑基：补足亏损，调和气血，疏通经脉，为炼丹作准备。此阶段重在养生、调息、导引。
  • 炼精化气：以神驭气，以气化精，使后天之精返为先天之气。此阶段小周天功夫，运转河车。
  • 炼气化神：气满丹田，自然上冲，通三关，过九窍，入泥丸。气化为神，神光内照。
  • 炼神还虚：神归虚无，与道合一。此时形神俱妙，出有入无，与天地同流。

外丹四法

外丹之学，以“鼎器、药物、火候、点化”为四法。

  • 鼎器：丹炉、丹鼎，以金铁为材，象天地之形。
  • 药物：铅汞、硫磺、硝石、朱砂、雄黄、雌黄、砒霜、矾石，各具其性，各显其用。
  • 火候：武火、文火、九转、七返，各有其法。
  • 点化：以药点石成金，以丹化质为灵。

服气诸法

  • 服食：服食草木、金石，以养形骸。
  • 咽津：漱咽津液，灌溉五脏。
  • 辟谷：不食五谷，食气而饱。
  • 房中：男女双修，取坎填离。

三、七元所成

由——丹脉之所从来

丹者之所由，或慕长生，慕道心切；或求飞升，志在凌云；或因病而修，身痛心悟；或因师而传，得闻大道。其由虽异，归丹则同。

形——丹脉之所形

  • 鼎炉之形：外丹鼎器，象天法地；内丹身形，自身即是鼎炉。
  • 丹药之形：外丹九转，丹成如珠；内丹凝结，丹成无形而有象。
  • 丹士之形：
    • 面色润而内敛：不若平人之红润浮面，乃如璞玉，光不外烁。
    • 目光定而有神：视物不瞬，凝然有摄力。
    • 呼吸深而微徐：息入至脐，出若春蚕吐丝。
    • 四末温而不灼：手足常温，虽冬不冰，虽劳不蒸。
    • 年高而步轻：齿或落而腰不伛，发或白而膝不软。

感——丹脉之所感

  • 感药物之化：铅汞交而真种生，水火济而丹砂成。丹士能感药物之变化，知火候之进退。
  • 感气机之动：丹田暖而气动，河车转而气行。丹士能感气机之动静，知周天之度数。
  • 感天地之交：冬至一阳生，夏至一阴生。丹士能感天地之气，而调自身之火。

用——丹脉之所用

  • 以丹养生：服食丹药，可以驻颜延年；内丹有成，可以形神俱妙。
  • 以丹疗病：丹砂、雄黄、水银、砒霜，皆可入药，以毒攻毒，以丹愈病。
  • 以丹成仙：丹道之极，形神俱妙，飞升成仙。

流——丹脉之所流

  • 外丹之流：自葛洪集大成，历代帝王多好之。唐之太宗、宪宗，皆服丹而崩；宋之徽宗，自号道君皇帝。
  • 内丹之流：自钟吕开派，分南北二宗。南宗主命功，北主性功。元明以降，全真一统。
  • 医丹之流：孙思邈开医丹合一，陶弘景融医于丹。后世医家，多通丹道。

传——丹脉之所传

  • 师徒之传：钟离权传吕洞宾，吕洞宾传刘海蟾，刘海蟾传张伯端，丹道一脉，以心传心。
  • 典籍之传：《参同契》《悟真篇》《黄庭经》《阴符经》，千载流传，不绝如缕。
  • 口诀之传：丹道要旨，多在口诀，不著文字。火候之妙，药物之真，非口传心授不得其门。

化——丹脉之所化

  • 陈化：丹药愈陈愈灵，九转丹成，岁月之功。内丹愈久愈纯，年高而神全。
  • 熟化：外丹九蒸九晒，水火炼之；内丹九转周天，以火炼之。
  • 气化：人用入之，人气入焉。丹士炼丹，以己之神火，化己之药物。

四、六论所明

象数

丹脉之数，九转、七返、八还、九鼎。河图之数，洛书之数，皆丹法所用。一六共宗为水，丹法取之以润下；二七同道为火，丹法取之以炎上。

阴阳

丹法以阴阳为用，取坎填离，水火既济。坎为水，中有真阳；离为火，中有真阴。取坎中之阳，填离中之阴，乃成纯阳之体。

五行

丹法以五行为基，金木交并，水火既济，土为黄婆。铅属金，汞属木，丹法取金木交并；砂属火，水银属水，丹法取水火既济；土居中调和，为黄婆。

干支

丹法以干支纪时，子午抽添，卯酉沐浴。子时一阳生，宜进火；午时一阴生，宜退符。卯酉二时，阴阳平分，宜沐浴停功。

三易

  • 简易：丹道之要，不过阴阳交媾、水火既济而已。至简至易，唯在真传。
  • 变易：火候之进退，药物之老嫩，随人随时而变。活子时，活午时，变易无常。
  • 不易：丹道之理，万古不易。铅汞之性，阴阳之道，长生之旨，终古如斯。

解字

  • 丹从井从丶，井象炼丹之器，丶象丹成之点。丹者，炼成之精也。
  • 鼎从鼎，象三足两耳之形。鼎者，炼丹之器也。
  • 炉从火从户，象火在户中。炉者，起火之处也。
  • 药从艹从乐，艹象草木，乐象调协。药者，调和之品也。

五、常象七则

  1. 面色润而内敛：不若平人之红润浮面，乃如璞玉，光不外烁。
  2. 目光定而有神：视物不瞬，凝然有摄力。
  3. 呼吸深而微徐：息入至脐，出若春蚕吐丝。
  4. 四末温而不灼：手足常温，虽冬不冰，虽劳不蒸。
  5. 年高而步轻：齿或落而腰不伛，发或白而膝不软。
  6. 食少而神旺：日进一餐，酬应如常。
  7. 不药而愈：小恙不假汤药，调息数日自平。

六、偏征五则

  1. 贪外丹而损内功：炼铅炼汞，服石服硫，药成而身废。此丹之偏，重外轻内。
  2. 重术轻道：专求小法，搬运周天，气行而神昏。此丹之偏，重术轻道。
  3. 强闭致壅：意守太过，气滞成痞。此丹之偏，用意过度。
  4. 辟谷成怯：强行断食，中气先馁。此丹之偏，强行辟谷。
  5. 以房为采：误读阴阳，肆行采战，竭精耗真。此丹之偏，以邪为正。

七、调摄之要

丹者偏于炼，当以养济之。

  • 归脉：知丹道本为养生，非为炫奇。归其本心，养其元气。
  • 复命：返观内照，复其天命。不贪长生，但求尽年。
  • 节宣：节其火候，宣其气机。不强行，不勉强，顺其自然。
  • 知时：知四时之序，应天时而动。春生夏长，秋收冬藏，丹道亦然。

八、归改之门

  • 若金石已伤：可入医脉，以药石自救。砒霜之毒，绿豆可解；铅汞之伤，甘草可和。
  • 若气滞已深：可入经脉，以针艾通之。气滞于中，针之可通；气郁于内，艾之可散。
  • 若心术已邪：可入隐脉，以虚静洗心。以静破执，以虚化实。

九、丹脉所归典籍

  • 《参同契》：丹经之祖，魏伯阳著，假借爻象以论作丹。
  • 《抱朴子》：外丹大成，葛洪著，内外篇各二十卷。
  • 《黄庭经》：存思之宗，魏华存传，内外景二十四章。
  • 《阴符经》：丹道心法，托名黄帝，三百余字尽道之妙。
  • 《悟真篇》：内丹正宗，张伯端著，诗词九十九首论丹。
  • 《指玄篇》：陈抟著，论内丹玄旨。
  • 《坐忘论》：司马承祯著，融丹于隐。
  • 《天隐子》：司马承祯著，论神仙之道。
  • 《入药镜》：崔希范著，论内丹火候。
  • 《金丹大要》：陈致虚著，元丹经集大成。
  • 《性命圭旨》：明尹真人传，性命双修之要。

十、丹脉总要

丹脉者，炼形化气之脉也。

宗魏葛陶孙，法内外丹道，鼎炉药物，火候为要。

由形感用流传化，七元备焉；象数阴阳五行干支三易解字，六论明焉。

常象七则，可以观德；偏征五则，可以察失；调摄之要，可以养中；归改之门，可以救偏。

丹非金石，乃性命也；炼非强为，乃自然也。丹道之极，形神俱妙；丹道之归，与道合一。

此丹脉之所以立，亦至人之所以成也。
