序曰

平人医宗，开病脉证治以纳万疾。
甲部总论病脉证治，立医道之纲。
乙部本体感知，立医道之本——病始于此，愈终于此。
丙部脏腑辨证，为诸部之枢。
诸部者，皆以丙部为根，从不同维度解构脏象，各自形成完备之病脉证治体系。
入诸部者，必归于脏；出诸部者，必验于乙。

卷一·总纲：六门皆归于脏

脏者，一身之枢也。
肝心脾肺肾，藏精气神；胆小肠胃大肠膀胱三焦，传化物而不藏。
一切病，皆可推衍至脏；一切治，皆可归原于脏。

六门者，六种入脏之径：

  • 经门（戊部·三脉辨证）——从经入脏。经气为径，脏腑为宅。自成体系：十二经、奇经八脉病脉证治。
  • 时门（丁部·六经辨证）——从时入脏。时序为径，气化为机。自成体系：六经传变、气化病脉证治。
  • 形门（庚部·形体辨证）——从形入脏。筋骨为径，五脏所主。自成体系：五体病、伤科病脉证治。
  • 动门（己部·导引辨证）——从动入脏。劳逸为径，用废为机。自成体系：动静失衡病脉证治。
  • 神门（壬部·祝由辨证）——从神入脏。神志为径，五志为机。自成体系：情志病、神气病脉证治。
  • 实门（辛部·微观辨证）——从实入脏。实体为径，器质为机。自成体系：癥瘕积聚病脉证治。

六门之外，尚有：

  • 本门（乙部·本体感知）——从感入脏。患者所觉，脏之应也。一切病之始、一切愈之终。
  • 统门（甲部·病脉证治）——从纲入脏。四字为纲，九门为目。医道之统摄、临证之总纲。
  • 枢门（丙部·脏腑经络）——形质相合。辨证所系，六门为解。原初之医理、各类之维系。

卷二·六门入脏解构

一、经门（戊部·三脉辨证）

入脏之径：十二经气、奇经八脉。
解构之法： 经气者，脏气之通路也；经病者，脏气之先兆也；穴应者，脏气之投影也。
自成体系： 十二经病脉证治（是动病、所生病）；奇经八脉病脉证治（冲任督带、阴阳二维、阴阳二跷）；穴应病脉证治（原穴、背俞穴、募穴、郄穴、下合穴）。
归脏之要： 手太阴经病归之于肺，足厥阴经病归之于肝，冲任病归之于肝肾，督脉病归之于肾与诸阳。
验于乙部： 经气通则患者觉舒，穴应消则患者觉安。

二、时门（丁部·六经辨证）

入脏之径：六经气化、时序传变。
解构之法： 六经者，脏气之时相也；传变者，脏气之移易也；气化者，脏气之应天也。
自成体系： 太阳病脉证治（膀胱、小肠气化病）；阳明病脉证治（胃、大肠气化病）；少阳病脉证治（胆、三焦气化病）；太阴病脉证治（脾、肺气化病）；少阴病脉证治（心、肾气化病）；厥阴病脉证治（肝、心包气化病）；传变规律（循经传、越经传、直中）。
归脏之要： 太阳病愈则膀胱、小肠气化复常；阳明病愈则胃、大肠传导复常；余经仿此。
验于乙部： 六经和则患者觉身和，传变止则患者觉病退。

三、形门（庚部·形体辨证）

入脏之径：五体所主、筋骨皮肉脉。
解构之法： 肝主筋，筋病归肝；心主脉，脉病归心；脾主肉，肉病归脾；肺主皮，皮病归肺；肾主骨，骨病归肾。
自成体系： 筋伤病脉证治（伤筋、筋挛、筋痿）；骨伤病脉证治（骨折、骨错、骨痹）；皮肉伤病脉证治（疮疡、肿毒、外伤）；脉管病脉证治（脉痹、静脉曲张）。
归脏之要： 筋病治肝不治筋，骨病治肾不治骨，余体仿此。
验于乙部： 形正则患者觉身正，伤愈则患者觉痛止。

四、动门（己部·导引辨证）

入脏之径：劳逸所伤、用废所病。
解构之法： 过劳者，脏气之耗也；过逸者，脏气之滞也；失衡者，脏气之乱也。
自成体系： 劳力伤病脉证治（伤气归脾肺）；劳神伤病脉证治（伤血归心肝）；房劳伤病脉证治（伤精归肾）；过逸病脉证治（气滞归肝、血瘀归心、湿困归脾）；失衡病脉证治（动静失宜、作息失度）。
归脏之要： 劳力伤补脾肺，劳神伤养心肝，房劳伤填肾精，过逸通其滞。
验于乙部： 动止和则患者觉有力，劳逸调则患者觉不疲。

五、神门（壬部·祝由辨证）

入脏之径：五志所伤、神气所病。
解构之法： 喜伤心，怒伤肝，思伤脾，悲伤肺，恐伤肾；神者心之所藏，魂者肝之所藏，魄者肺之所藏，意者脾之所藏，志者肾之所藏。
自成体系： 情志病脉证治（郁、狂、癫、痫、惊、悸）；神气病脉证治（失神、失魂、失魄、失意、失志）；怪病脉证治（诸药不效、诸医不解）。
归脏之要： 喜伤心治心，怒伤肝治肝，思伤脾治脾，悲伤肺治肺，恐伤肾治肾。
验于乙部： 神安则患者觉心安，志定则患者觉不恐。

六、实门（辛部·微观辨证）

入脏之径：实体所病、器质所变。
解构之法： 癥瘕积聚，脏气之结也；息肉结节，脏气之凝也；肿瘤恶变，脏气之败也。
自成体系： 癥瘕病脉证治（坚者削之）；积聚病脉证治（留者攻之）；息肉结节病脉证治（结者散之）；异物病脉证治（有者除之）。
归脏之要： 肝之癥治肝，脾之积治脾，肺之结节治肺。
验于乙部： 实体消则患者觉块消，器质复则患者觉功能复。

卷三·诸部归脏示例

例一：头痛

  • 经门入：太阳经头痛，刺攒竹、天柱 → 归膀胱
  • 时门入：太阳病头痛，桂枝汤 → 归膀胱、小肠
  • 形门入：颈椎病头痛，正骨理筋 → 归肝（筋）、肾（骨）
  • 动门入：久坐劳倦头痛，导引休息 → 归脾（劳倦伤气）
  • 神门入：忧思过度头痛，祝说安神 → 归心（神）、脾（思）
  • 实门入：脑瘤头痛，手术切除 → 归脏之实体

六门入路不同，皆归脏。
六门治法不同，皆验于乙——患者觉头痛止。

例二：不寐

  • 经门入：心经病不寐，刺神门 → 归心
  • 时门入：少阴病不寐，黄连阿胶汤 → 归心、肾
  • 形门入：久卧伤气不寐，导引动形 → 归脾（气）、心（神）
  • 动门入：劳神过度不寐，息心静坐 → 归心、肝
  • 神门入：惊恐不寐，祝说安神 → 归心（神）、肾（恐）
  • 实门入：脑部器质病不寐，治其本 → 归脏之实体

六门入路不同，皆归脏。
六门治法不同，皆验于乙——患者觉能寐。

卷四·平人医宗三阶（六门通用）

一阶：择门入脏

小疾初起，择门而入，归脏而治：

  • 头痛：择经门入，归膀胱 → 刺攒竹
  • 不效，更择形门入，归肝（筋）→ 正颈椎
  • 不效，更择神门入，归心（神）→ 安其心

一入门而愈者，不必入六门。
一入门不愈者，更择他门。

二阶：家医六门

家人有病，辨其当入何门、当归何脏：

  • 父腰痛：择形门入，归肾（骨）→ 正骨；兼入动门，归脾（劳倦）→ 息劳
  • 母不寐：择神门入，归心（神）→ 安神；兼入经门，归心经 → 刺神门
  • 子发热：择时门入，归肺（太阳）→ 解表；兼入实门，查实体 → 无则安

三阶：传灯六门

能授一人知六门、归五脏：

  • 授其择门之法
  • 授其归脏之要
  • 授其验乙之终

能使一家之人，小疾自择门、大疾知归脏、久疾知转门。

卷五·平人医宗与三常

平人常象：全具而常，以此为基。
平人医宗：九门入路，归脏而治，验于乙部。

与至人：

  • 至人入其修门，平人入其病门
  • 同疾而不同门，同脏而不同治
  • 至人以修愈者，平人以医愈

与缺弊：

  • 缺弊入其缺门，平人入其全门
  • 同疾而不同门，同脏而不同本
  • 缺弊以缺成者，平人以全养

卷末·一灯

九门者，九种治病之阶。
六门者，六种解构之法。
入门而不知归脏，犹入室而不登堂。
归脏而不验于乙，犹治病而不问人。
丙部为枢，诸部为用。
乙部为本，甲部为纲。
九门通，平人可愈。
九门传，平人可医。

—— 平人医宗篇终

丙部乃成三常三宗：

  • 平人常象·平人医宗（六门归脏）
  • 至人常象·至人医宗（八脉归脏）
  • 缺弊常象·缺弊医宗（九象归脏）

三常立本，三宗愈病。
六门八脉九象，皆归脏；
诸部诸法诸治，皆验乙。
医道之大，无遗类矣。
