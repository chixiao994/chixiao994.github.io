平人常象有三，一曰当下之常，二曰脏腑之常，三曰天年之常。

甲·当下之常

临证之时，只需记，

  • 眠不安，问心肝胃；
  • 食不知，问脾胃；
  • 渴不渴，问肺肾；
  • 二便调否，问脾肾小肠大肠膀胱；
  • 手足温否，问心脾；
  • 经期准否，问肝冲任。

乙·脏腑常象

一、肝之常

经曰：“肝者，将军之官，谋虑出焉。”
经曰：“肝藏血，血舍魂。”
经曰：“肝气通于目，肝和则目能辨五色。”
经曰：“足厥阴肝脉……布胁肋，循喉咙，连目系。”

常象七则：

  1. 眠稳无梦——魂归于肝，夜卧则藏。常者合目即寐，一夜无惊魇，无梦呓，醒后神清。
  2. 目得血而能视——常者目睛润泽，久视不涩，昼不畏光，暮不昏花。
  3. 爪甲荣润——肝之华在爪。常者甲色淡红，坚而不脆，平而有华。
  4. 筋柔有力——肝主筋。常者肢体柔韧，屈伸自如，不挛不痿。
  5. 胁无胀痛——肝经布胁。常者胁肋空旷，无胀、无闷、无牵掣。
  6. 情志调畅——肝主疏泄。常者遇事能谋，怒生即散，不郁不亢。
  7. 应时而和——肝应春。常者春时脉生，不病眩、不病厥。

二、心之常

经曰：“心者，君主之官，神明出焉。”
经曰：“心藏脉，脉舍神。”
经曰：“心气通于舌，心和则舌能知五味。”
经曰：“其华在面，其充在血脉。”

常象六则：

  1. 寐则神敛——心舍神。常者入夜神归其舍，不烦不躁，合目即寐。
  2. 面有华色——其华在面。常者面色明润，如缟裹朱，不赤不白不青不黯。
  3. 舌能知味——心气通舌。常者舌体柔和，味觉敏常，不麻不涩。
  4. 脉应四时——心主血脉。常者脉象和缓，应春弦、夏洪、秋毛、冬石。
  5. 喜乐有节——心在志为喜。常者遇喜能乐，乐止即平，无狂无悲。
  6. 胸中宽舒——心居胸中。常者胸廓清虚，无闷无悸无痛。

三、脾之常

经曰：“脾者，仓廪之官，五味出焉。”
经曰：“脾藏营，营舍意。”
经曰：“脾气通于口，脾和则口能知五谷。”
经曰：“其华在唇四白，其充在肌。”

常象七则：

  1. 口知五谷味——脾气通口。常者饥而知食，食而知味，不口淡、不口甘、不口腻。
  2. 食后不倦——脾主运化。常者食毕神清，不困不胀，不恶食不消谷。
  3. 肌肉充润——脾主肌肉。常者四体丰匀，不痿不削，不浮不肿。
  4. 唇华如帛——其华在唇。常者唇色淡红，润而不干，不缩不肿。
  5. 思虑有节——脾在志为思。常者遇事能思，思止即释，不结不郁。
  6. 二便调顺——脾主运化水湿。常者大便日一行，不溏不结；小便清利，不频不利。
  7. 四肢温润——脾禀气于胃，四末之本。常者手足温，不寒不热不潮。

四、肺之常

经曰：“肺者，相傅之官，治节出焉。”
经曰：“肺藏气，气舍魄。”
经曰：“肺气通于鼻，肺和则鼻能知香臭。”
经曰：“其华在毛，其充在皮。”

常象六则：

  1. 鼻知香臭——肺气通鼻。常者鼻窍通利，不塞不涕，嗅而知臭。
  2. 呼吸微徐——肺主气。常者呼吸平顺，不促不喘，息深而匀。
  3. 皮毛润泽——其华在毛。常者皮肤润而不燥，毛发光泽，不枯不脱。
  4. 不病咳喘——肺主肃降。常者咽喉清利，不痒不呛，四时无咳。
  5. 音声清亮——肺主声。常者语声清，不嘶不哑，不高不怯。
  6. 水道通调——肺通调水道。常者小便如常，无因咳而遗、无因悲而溺。

五、肾之常

经曰：“肾者，作强之官，伎巧出焉。”
经曰：“肾藏精，精舍志。”
经曰：“肾气通于耳，肾和则耳能闻五音。”
经曰：“其华在发，其充在骨。”

常象七则：

  1. 耳聪闻远——肾气通耳。常者听觉敏常，不鸣不聋，高下皆闻。
  2. 发泽不堕——其华在发。常者发润有泽，壮年不白，暮年不脱。
  3. 骨强齿固——肾主骨，齿为骨余。常者腰脊有力，齿无动摇。
  4. 夜卧不溲——肾司二便。常者夜卧小便不过一，不起不频。
  5. 喘息深沉——肾主纳气。常者动而不喘，登高不促，息能至脐。
  6. 志定不恐——肾在志为恐。常者临事不怯，无故不惊，不善恐、不妄想。
  7. 应冬而藏——肾应冬。常者冬时精藏，不病痿厥、不病飧泄。

六、胃之常

经曰：“胃者，仓廪之官，五味出焉。”
经曰：“胃为水谷之海。”
经曰：“胃不和则卧不安。”

常象四则：

  1. 饥饱有节——胃主受纳。常者知饥知饱，不暴食、不厌食、不饥而不欲食。
  2. 食后无胀——胃主腐熟。常者食后胃脘舒和，无痞无满无反酸。
  3. 暮食能化——胃主降浊。常者晚餐能消，就寝不翻、不噎、不嘈。
  4. 口无异味——胃气通口。常者口和不渴，无酸无苦无腐。

七、小肠之常

经曰：“小肠者，受盛之官，化物出焉。”
经曰：“小肠主液。”

常象二则：

  1. 小便清长——小肠主液。常者小便日四五行，色清不黄，无涩无频。
  2. 便前无痛——小肠主受盛。常者大便前脐腹平和，无绞痛、无急迫。

八、大肠之常

经曰：“大肠者，传导之官，变化出焉。”

常象二则：

  1. 晨起一解——大肠主传导。常者黎明或晨起排便，一日一行。
  2. 形色黄条——常者便形成条，色黄不黑，不粘不硬。

九、膀胱之常

经曰：“膀胱者，州都之官，津液藏焉，气化则能出矣。”

常象二则：

  1. 小便有力——膀胱主气化。常者小便出时有势，不待力、不涩痛。
  2. 溺后即净——常者溺毕爽利，无余沥、无滴沥。

十、胆之常

经曰：“胆者，中正之官，决断出焉。”

常象二则：

  1. 临事能断——胆主决断。常者遇事不犹豫，不反复，不惊悸。
  2. 口和不苦——胆藏精汁。常者口无异味，不苦不腻。

十一、三焦之常

经曰：“三焦者，决渎之官，水道出焉。”

常象二则：

  1. 水道通调——上焦如雾，中焦如沤，下焦如渎。常者无水肿、无癃闭、无胀满。
  2. 气机流畅——三焦主气。常者胸腹空旷，无闷无痞。

十二、心包之常

经曰：“膻中者，臣使之官，喜乐出焉。”（《素问·灵兰秘典论》——膻中即心包）
经曰：“心主手厥阴心包络之脉，起于胸中，出属心包络，下膈，历络三焦。”（《灵枢·经脉》）
经曰：“诸邪之在于心者，皆在于心之包络。”（《灵枢·邪客》）

常象四则：

  1. 喜乐由衷——心包代心宣情。常者遇喜能笑，笑则由衷，不伪不郁，乐止即平。
  2. 胸中宽舒——心包居胸中，护心之外。常者胸廓空旷，无闷无压，无物梗噎。
  3. 手心温润——手厥阴经入掌中。常者手心温而不燥，润而不湿，不热不冷。
  4. 神不受惊——心包为心之藩篱。常者遇变不悸，乍闻不惊，无故不恐。

附：心包之常何以别于心

  • 心主神明之舍，心包主神明之卫。
  • 心之常重在寐、面、舌、脉，是君主自持之象；
  • 心包之常重在喜乐、胸宽、手心、定惊，是藩篱固守之象。
  • 心受邪则神昏，心包受邪则但胸满、心悸、掌中热——藩篱未破，君主尚安。

至此，五脏、六腑、心包——十二官常象始全。

丙·天年常象

经曰：“女子七岁，肾气盛，齿更发长……四七，筋骨坚，发长极，身体盛壮……七七，任脉虚，太冲脉衰少，天癸竭，地道不通，故形坏而无子也。丈夫八岁，肾气实，发长齿更……八八，则齿发去……五脏皆衰，筋骨解堕，天癸尽矣。”
经曰：“上古之人，其知道者，法于阴阳，和于术数，食饮有节，起居有常，不妄作劳，故能形与神俱，而尽终其天年，度百岁乃去。”

一、常象定义

天年常者，五脏时序之全相也。
非一脏之功，乃肝心脾肺肾各当其位、各守其度、各尽其岁，而后成此象。

二、常象五则

  1. 齿发之更迭应时 —— 童稚：齿更、发长，不迟不早。壮年：发泽齿固，不堕不摇。暮年：齿落发白，不先于八八、七七。过迟者肾气不充，过早者精竭于先。
  2. 天癸之至竭应期 —— 女子二七至七七，天癸应时下、应时竭。男子二八至八八，天癸应时盛、应时尽。不至者先天不立，不竭者藏令失度。
  3. 形骸之用能尽其年 —— 少时筋骨柔韧，壮时筋骨坚劲，老时筋骨懈堕——各得其时，不提前、不延后。三十不驼，六十不倒，八十不废床笫。
  4. 神志之变与年俱谐 —— 童稚志未定而嬉；壮年志盛而任事；暮年志藏而好静。非呆钝，非躁妄，非未老先衰之神昏。
  5. 尽其天年，度百岁乃去 —— 非必百岁，而是终其禀赋之数。不夭折不中殇，不病卧经年而卒。

三、常变之用

发育迟缓者——天年至而未至。

  • 女子过二七天癸未至；
  • 男子过二八精气未盛；
  • 童稚当齿更时不更、当发长时不长。
  • 此五脏不立，尤责之肾。

早衰者——天年未至而已至。

  • 年未四十，齿摇发白；
  • 年未五十，天癸早竭；
  • 年未六十，筋骨懈堕、耳目失用。
  • 此五脏先竭，尤责之肾，亦责之七情、劳伤、摄养失度。

结语

此平人三常并立：

  • 无当下之常，人不能安于一日。
  • 无本脏之常，人不能和于四时。
  • 无天年之常，人不能尽其天命。
