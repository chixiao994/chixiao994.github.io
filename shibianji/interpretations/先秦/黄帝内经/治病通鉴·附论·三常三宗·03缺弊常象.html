序曰

医经立常，始于平人，扩于至人。
平人者，全具而和；至人者，异禀而修。
然天地生人，有全必有缺。有生而目不明者，有生而耳不聪者，有生而足不健者，有生而言不利者；亦有后天所伤，兵燹、疾厄、事故，夺其一官、损其一体者。
此非病，乃缺弊。
缺弊者，以平人常衡之，满目皆“不及”。然其不及，非不欲全，乃不能全。
不能全而求全，终身困于缺；
能知其缺、安其缺、用其缺，乃能成其人。
昔者师旷瞽而审音，左丘失明而著《国语》，孙子膑脚而修《兵法》，司马迁刑余而作《史记》。此数子者，非以缺废，乃因缺成。
缺者，非天夺其成，乃天示其径。
今为缺弊者立常，非以平人矩矱绳之，乃以不全为本，以能达为阶，以成事为归。
常象既立，缺弊者有径可入，有阶可登，有成可期。
此丙部之终章，亦医道之大仁。

卷一·总纲：缺弊常象三义

一曰缺为本
缺弊者，以此缺为本。
不以平人全具责其缺，不以至人异禀望其全。
目不明者，不以辨色责之；耳不聪者，不以审音望之；足不健者，不以趋走期之。
缺即是本，本立则道生。

二曰达为阶
缺弊者，亦有可达。
非达于全，乃达于尽其缺、用其缺、成于缺。
目不明者，可达于听微、可达于触敏、可达于心通。
耳不聪者，可达于察色、可达于观气、可达于神会。
足不健者，可达于手巧、可达于思深、可达于坐忘。
达者，非补其缺，乃成其用。

三曰成为归
缺弊者，亦有可成。
非成于全人，乃成于以其缺而成一事、立一业、传一灯。
师旷瞽而成音律之祖，是成。
左丘盲而成史家之宗，是成。
孙子膑而成兵家之圣，是成。
司马迁刑而成史家之绝唱，是成。
成者，缺不能限，人不能夺。

卷二·缺弊九象

一、目缺者之常

象曰：目不明，或全盲，或弱视，或夜盲，或色盲。

常象四则：

  1. 听微——目无所用，耳极其聪。闻声知人，闻言知心，闻息知病。
  2. 触敏——手代目用，触而知形，抚而知质，按而知应。
  3. 心通——目不外驰，神易内守。接人接物，往往直入本心。
  4. 记强——闻之不漏，历之不亡，心中自有光明藏。

偏征二则： 1.疑人——不见则不信，不信则多疑，多疑则孤。 2.自锢——以盲自废，不敢行、不敢试、不敢为。

日课三阶： 初阶：习听辨、习触辨、习心记。 中阶：择一艺专修，如琴、如医、如推拿。 高阶：以其所成，授人、传灯。

归改之门： 疑人者，从信一师、交一友始；自锢者，从行一事、成一器始。

二、耳缺者之常

象曰：耳不聪，或全聋，或重听，或失音（聋哑）。

常象四则：

  1. 察色——耳无所用，目极其明。观色知意，观形知情，观微知变。
  2. 观气——静极而观，能见人之气色、物之气象、时之气机。
  3. 神会——不待言说，直入本心；不待解释，直契本意。
  4. 心静——不入喧嚣，易入静定；不闻杂音，易守本心。

偏征二则： 1.多疑——听不见则不知，不知则猜，猜则多疑。 2.孤僻——与人难通，渐离人群，自闭自囚。

日课三阶： 初阶：习观色、习读唇、习书问。 中阶：择一艺专修，如画、如书、如医（望诊）。 高阶：以其所成，授人、传灯。

归改之门： 多疑者，从日行一善、日交一人始；孤僻者，从入一事科、成一事始。

三、足缺者之常

象曰：足不健，或跛、或瘫、或痿、或截。

常象四则：

  1. 手巧——足不能行，手代足用。手极其灵，能成细工、能作精器。
  2. 思深——动少则静多，静多则思深。能入幽微，能见深远。
  3. 坐忘——久坐成习，能入静定，能得坐忘。
  4. 耐寂——不能逐外，易归内守，耐得寂寞，守得本心。

偏征二则： 1.郁结——困于一隅，久则生郁，郁则伤身。 2.倚人——行动需人，久则生倚，倚则失立。

日课三阶： 初阶：习手巧、习思辨、习静坐。 中阶：择一艺专修，如雕、如画、如算、如医。 高阶：以其所成，授人、传灯。

归改之门： 郁结者，从日课一事、月成一器始；倚人者，从能自了、能助人始。

四、言缺者之常

象曰：言不利，或口吃、或失音、或哑。

常象四则：

  1. 意深——言不能多，言必有物；语不能速，语必及义。
  2. 听敏——己不言，善听人言；听而能记，记而能思。
  3. 笔健——口不能言，笔代口用。能书、能文、能达意。
  4. 心诚——言不轻发，发则必诚；语不轻许，许则必践。

偏征二则： 1.畏人——惧言而畏人，畏人而避世。 2.郁塞——欲言不能，久则郁塞，塞则伤神。

日课三阶： 初阶：习笔谈、习书问、习日录。 中阶：择一艺专修，如书、如文、如医（笔诊）。 高阶：以其所成，授人、传灯。

归改之门： 畏人者，从交一友、日书一问答始；郁塞者，从日录一得、月成一文始。

五、形缺者之常

象曰：形不全，或侏儒、或畸形、或毁容。

常象四则：

  1. 内修——形不炫人，反归内修。德性、智慧、技艺，皆可过人。
  2. 心韧——久处异眼，心志得砺。能忍人所不能忍，能成人所不能成。
  3. 善喻——己身之缺，能喻人苦；己心之韧，能励人志。
  4. 忘形——形既不足恃，反易忘形。忘形者，易入神。

偏征二则： 1.自弃——以形自弃，不敢见人、不敢应世、不敢有为。 2.怨世——以形怨世，怨天尤人，终其身不能自解。

日课三阶： 初阶：习内省、习一艺、习应事。 中阶：择一业深耕，能自养、能助人。 高阶：以其所成，授人、传灯。

归改之门： 自弃者，从日行一善、日见一人始；怨世者，从读一传、知一人苦始。

六、智缺者之常

象曰：智不足，或生而愚钝，或病而损智，或老而健忘。

常象四则：

  1. 朴直——智不足则巧不生，巧不生则朴直存。朴直者，人信之。
  2. 专一——不能兼通，反能专一。一事重复千万遍，能成绝技。
  3. 心善——智不足则机心少，机心少则本心显。本心显者，多善良。
  4. 知足——不能多求，反易知足。知足者，常乐。

偏征二则： 1.易欺——朴直而易欺，易欺而屡伤。 2.自卑——自知不足而自卑，自卑而自废。

日课三阶： 初阶：习一事、专一艺、守一业。 中阶：以此一事一艺，能自养、能助人。 高阶：以其所成，授人、传灯。

归改之门： 易欺者，从依一可信人、守一可信条始；自卑者，从日成一事、月成一器始。

七、貌缺者之常

象曰：貌不扬，或丑、或陋、或有异于人。

常象四则：

  1. 不恃貌——貌无可恃，反不恃貌。不恃貌者，不求悦人，不求媚世。
  2. 修内美——外无可炫，反修内美。德性、才华、器识，皆可成美。
  3. 识人真——己不以色取人，亦不以色度人。能见人真，能交人深。
  4. 忘相——貌既不足恃，反易忘相。忘相者，易见道。

偏征二则： 1.自惭——以貌自惭，不敢见人、不敢应世。 2.激世——以貌激世，以怪骇人、以异凌人。

日课三阶： 初阶：修一艺、读一书、交一友。 中阶：以此一艺一书，能自养、能助人。 高阶：以其所成，授人、传灯。

归改之门： 自惭者，从日见一人、日行一善始；激世者，从读一圣贤传、行一平常事始。

八、老缺者之常

象曰：老而衰，或目昏、耳聋、齿脱、发白、步迟、忘事。

常象四则：

  1. 经历富——老而衰者，经历富。所历之事、所见之人、所经之变，皆可授人。
  2. 心渐平——老而衰者，心渐平。不争、不躁、不妄、不执。
  3. 知轻重——老而衰者，知轻重。何事当为，何事不当为；何言当说，何言不当说。
  4. 传灯心——老而衰者，知时日无多，传灯之心自生。

偏征二则： 1.自弃——以老自弃，不修、不学、不为。 2.怨时——以老怨时，怨天、怨人、怨命。

日课三阶： 初阶：日行三千步、日读一页书、日录一得。 中阶：以此一生所积，授一人、传一艺。 高阶：以其所传，再传、三传，灯灯不绝。

归改之门： 自弃者，从日行一善、日录一得始；怨时者，从读一少年书、交一忘年友始。

九、幼缺者之常

象曰：幼而缺，或先天不足，或幼年所伤，终身带之。

常象四则：

  1. 早知缺——幼而知缺，早知人世之难，早知自处之道。
  2. 韧性生——幼而带缺，韧性与生俱来。能忍人所不能忍，能成人所不能成。
  3. 善体人——己身有缺，能体人苦。长大成人，多善体恤、善助人。
  4. 早立志——缺在幼年，志在少年。不待中年，已知此生何为。

偏征二则： 1.自怜——以缺自怜，求人怜、求人助、求人免。 2.怨亲——以缺怨亲，怨父母、怨天地、怨命运。

日课三阶： 初阶：习一事、专一艺、守一业。 中阶：以此一事一艺，能自养、能助人。 高阶：以其所成，授人、传灯。

归改之门： 自怜者，从日行一善、日助一人始；怨亲者，从读一圣贤幼年传、知古人苦始。

卷三·缺弊通义

九象非九途，乃九种缺、九种径。

  • 目缺者，可以听入、以触入、以心入。
  • 耳缺者，可以色入、以气入、以神入。
  • 足缺者，可以手入、以思入、以坐入。
  • 言缺者，可以笔入、以文入、以诚入。
  • 形缺者，可以内修入、以心韧入、以善喻入。
  • 智缺者，可以朴直入、以专一入、以本心入。
  • 貌缺者，可以内美入、以真识入、以忘相入。
  • 老缺者，可以经历入、以平心入、以传灯入。
  • 幼缺者，可以早知入、以韧性入、以体人入。

缺者，非天夺其成，乃天示其径。
以缺为本，以达为阶，以成为归。

卷四·缺弊与平人、至人

平人者，全具而不知其全。
至人者，异禀而修其所长。
缺弊者，不全而用其所缺。

三者不同，皆可成人。

  • 平人可达至人——全具而修，可成异禀。
  • 缺弊可达至人——用缺而修，可成异禀。
  • 缺弊可达平人——尽其缺而不废，可成平常。

平人有平人之常，至人有至人之常，缺弊有缺弊之常。
