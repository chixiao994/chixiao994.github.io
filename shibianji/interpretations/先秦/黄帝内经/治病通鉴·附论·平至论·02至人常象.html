序曰

医经立常，止于平人。
平人者，食饮有节，起居有常，不妄作劳，尽终天年。此苍生之福，医道之基。
然天地生人，禀赋不齐。有生而筋骨异者，有幼而神明早慧者，有嗜一技如生命者，有闻大道而涕下者。
此非病，乃异禀。
异禀者，以平人常衡之，满目皆“过”与“不及”。然其过非妄，乃功法所需；其不及非虚，乃资粮所向。
至人者，异禀而能自明、自修、自调、自化者也。
今为至人立常，非以平人矩矱绳之，乃以功法为纲，以八脉为目，以日课为阶，以归改为救。
常象既立，异禀者有径可入，有偏可正，有归可依。
此丙部之新章，亦医道之未垦也。

卷一·总纲：至人常象三义

一曰功法之常
至人必有专修。或体、或法、或术、或医、或数、或艺、或事。
不以平人之“均衡”责其偏，而以功法之“自洽”观其成。

二曰资粮之常
至人各有其粮。体修需战，法修需静，术修需悟，医修需临证，数修需推演，艺修需磨砺，事修需应世。
不以平人之“饮食”一概论之，而问其功法所需足否、顺否。

三曰节宣之常
至人亦有过犹不及。体修过战则崩，法修过静则枯，术修过悟则浮，医修过劳则竭，数修过思则伤脾，艺修过执则碍道，事修过入则忘返。
此非病其功法，乃病其失衡。
节者，不使过也；宣者，不使滞也。节宣之间，至人之调摄在焉。

卷二·八脉常象

一、隐脉——守默全真之常

宗祖：老子、庄子、列子、文子
功法：守一、坐忘、心斋、朝彻、撄宁

常象七则：

  1. 外若不足，中实有余——形貌或朴讷，言语或希微，而神光内蕴，应机如响。
  2. 居简御繁——身居陋巷，不营产业，而事至能断，物来能应。
  3. 不争而善胜——不与人争名逐利，而德望自归。
  4. 知止不殆——位高则思退，功成则弗居。
  5. 独处不寂，处众不扰——静时不生孤苦，动时不失本守。
  6. 应物不伤——接人事而不疲，涉尘缘而不染。
  7. 年高而神全——鬓发虽白，目如秋水。

偏征五则： 1.槁木死灰 2.任放废事 3.避世自了 4.狂禅口头 5.以枯槁为寿。

调摄之要：隐者偏于静，当以动济之。导引、步趋、临事、接物，皆可破枯禅。

归改之门：若槁木已深，可入动脉、事脉，以行救废。

二、丹脉——炼形化气之常

宗祖：魏伯阳、葛洪、陶弘景、孙思邈
功法：内丹、外丹、服气、咽津、辟谷、房中

常象七则：

  1. 面色润而内敛——不若平人之红润浮面，乃如璞玉，光不外烁。
  2. 目光定而有神——视物不瞬，凝然有摄力。
  3. 呼吸深而微徐——息入至脐，出若春蚕吐丝。
  4. 四末温而不灼——手足常温，虽冬不冰，虽劳不蒸。
  5. 年高而步轻——齿或落而腰不伛，发或白而膝不软。
  6. 食少而神旺——日进一餐，酬应如常。
  7. 不药而愈——小恙不假汤药，调息数日自平。

偏征五则： 1.贪外丹而损内功 2.重术轻道 3.强闭致壅 4.辟谷成怯 5.以房为采。

调摄之要：丹者偏于炼，当以养济之。归脉、复命、节宣、知时。

归改之门：若金石已伤，可入医脉，以药石自救；若气滞已深，可入经脉，以针艾通之。

三、经脉——通调致和之常

宗祖：《灵枢》《甲乙》、华佗、扁鹊、杨继洲
功法：导引、按跷、针法、灸法、砭石

常象六则：

  1. 肤理柔韧——皮不糙涩，肉不板结，按之如绵，举之有弹。
  2. 关节流利——屈伸无滞响，转侧不牵强。
  3. 四末微温——手足掌心，煦如春阳。
  4. 虽劳不疲——终日操作，筋不酸、骨不楚。
  5. 应时知感——节气将变，身有先觉；非病，乃经气应天。
  6. 针感敏明——己受针，气至迅捷；施针于人，指下洞然。

偏征四则： 1.重通轻养 2.恃技耗神 3.以痛为效 4.废药废灸。

调摄之要：脉者偏于通，当以蓄济之。节针简砭，归养气血。

归改之门：若泻之已甚，可入丹脉，服气培元；若偏废他法，可入医科，复其全具。

四、数脉——观象知几之常

宗祖：京房、邵雍、陈抟、刘伯温
功法：易象、太玄、皇极、紫微、三命

常象六则：

  1. 临事不惑——事起仓促，人皆惶然，彼已决断。
  2. 遇变不惊——祸至能静，败至能待，不乱方寸。
  3. 进退有度——知时之可乘，亦知时之当止。
  4. 取予有时——不贪非分之得，不惧当与之失。
  5. 见微知著——事未形而几已动，人未言而意已会。
  6. 数不碍道——知命而不锢于命，推数而不役于数。

偏征四则： 1.以命自锢 2.以数为戏 3.强解强断 4.废人事而恃天命。

调摄之要：数者偏于推，当以行济之。一事之成，胜于百课。

归改之门：若锢数已深，可入事脉，以应世破执；若务虚已甚，可入艺脉，以成物立诚。

五、艺脉——游心寓巧之常

宗祖：伯牙、嵇康、王羲之、苏轼、计成
功法：琴、棋、书、画、茶、酒、香、园、墨、营造

常象六则：

  1. 手与器一——操琴则琴非外物，运笔则笔是指延。
  2. 作器时神凝——入技境，忘饥渴、废寝兴，出而神旺。
  3. 成器后心旷——物成，非以炫人，乃以自遣；观之悦然，即掷之不吝。
  4. 用物而不役于物——有好而不溺，有藏而不锢。
  5. 以艺通道——由技入，由器悟，一花一木，皆见天机。
  6. 器有德容——己之所制，温润雅正，不怪不戾。

偏征四则： 1.玩物丧志 2.以技炫人 3.有匠气无道心 4.锢于门户。

调摄之要：艺者偏于物，当以心济之。由技问理，由器见道。

归改之门：若匠气已深，可入隐脉，以虚其心；若丧志已久，可入事脉，以实其行。

六、动脉——以战养生之常

宗祖：黄帝（《素问》四时导引）、华佗（五禽）、张三丰（太极）、戚继光
功法：导引、武艺、耕稼、行脚、负任

常象五则：

  1. 筋骨柔而有力——不似石硬，而有百钧之任；不似藤软，而有千转之韧。
  2. 气血充而不浮——面不赤、脉不洪，而遇寒不栗、遇劳不喘。
  3. 虽老不衰——年七十，犹能负薪、驰马、履险。
  4. 虽劳不疲——终日操作，暮而神完。
  5. 战时不怯，止时不躁——临敌能静，息战能安。

偏征四则： 1.以战为命 2.以伤为荣 3.破而不立 4.竭而不休。

调摄之要：动者偏于耗，当以静济之。战后必养，劳后必息。

归改之门：若积损已深，可入经脉，以针艾修复；若心战已狂，可入隐脉，以守一平之。

七、医脉——愈人愈己之常

宗祖：岐伯、扁鹊、张机、孙思邈
功法：方脉、针灸、外治、食养、祝由

常象七则：

  1. 知常达变——于平人见微澜，于未病识将萌。
  2. 见微知著——闻声知证，切脉知机。
  3. 治人如治己——不轻用猛剂，不妄施酷针。
  4. 愈人不矜——功成弗居，愈而弗记。
  5. 己身先治——无病时调摄，小恙时自治，不以医者废己常。
  6. 不欺不炫——不知者不妄言，未明者不强治。
  7. 传灯不吝——遇可教者，倾囊授之。

偏征四则： 1.以医为市 2.恃术轻身 3.门户自囿 4.以病试药。

调摄之要：医者偏于劳，当以逸济之。日课导引，暮寝收神，不废己身。

归改之门：若心力已竭，可入隐脉，闭关以复；若贪执已深，可入事脉，临民以悟。

八、事脉——应世成务之常

宗祖：伊尹、管仲、诸葛亮、范仲淹、王阳明
功法：察势、任人、决疑、持重、行权

常象六则：

  1. 处高位而心愈下——位愈尊，礼愈恭；权愈重，行愈谨。
  2. 应繁剧而神愈闲——案牍如山，不焦不躁；变起仓促，不惊不乱。
  3. 功成不居——事成则退，名归则避。
  4. 事遂身退——知时知止，不待倾覆。
  5. 以天下为身——一身之病，即苍生之病；一身之愈，即天下之愈。
  6. 事中见道——不废事以求道，不逃世以全真。

偏征四则： 1.以天下为名 2.济人而自溺 3.事繁神耗 4.权谋入骨。

调摄之要：事者偏于耗，当以静济之。日课坐忘，暮寝收神，不废己身。

归改之门：若溺事已深，可入隐脉，闭关以复；若权谋已深，可入艺脉，游艺以洗。

卷三·日课阶

至人之成，非一日之功。然至人之始，必自日课起。

启蒙日课七科（童子入阁第一层）

  • 身科：晨课八段锦三式，暮省“今日身有滞否？”，器识导引图。
  • 医科：晨课自问六纲，暮省“今日食有味否、寐得深否？”，器识六纲尺。
  • 数科：晨课测日影，暮省“今日见几事？”，器识日晷。
  • 艺科：晨课研墨三合，暮省“今日手作物否？”，器识墨砚。
  • 武科：晨课拳经三势，暮省“今日战气平否？”，器识木剑。
  • 文科：晨课诵五言，暮省“今日录一字否？”，器识抄簿。
  • 事科：晨课行一善，暮省“今日济一人否？”，器识善录。

至人日课三阶（入脉后进阶）

  • 初阶：功法日课——择一脉，每日行其功法一刻，三月不辍。
  • 中阶：兼修日课——本脉之外，择一他脉，每旬习之，以济偏废。
  • 高阶：传灯日课——每月录一得，授一徒，答一问。

卷四·归改门

至人亦有走偏时。
走偏非耻，不知偏、不归改，乃为至人之失。

归改四诀：

  1. 识征——体修战而不养，面虽壮而内槁；法修丹而不功，药虽精而本竭；术修悟而不修，理虽通而基空。
  2. 不讳——见偏不掩，知过不饰。
  3. 择门——本脉已竭，不恋栈；他脉可济，不耻入。
  4. 重立——非废前功，乃续新程。体修归改入医脉，以药石救积损；法修归改入动脉，以导引通壅滞；术修归改入事脉，以应世破孤绝。

归改之后，仍是至人。

卷末·一灯

真人者，不可立常。
非不能也，不可也。
真人已出时序，不入方隅；提挈天地，把握阴阳。非常象所能羁，非篇幅所能尽。
然医者当知有此境。
知有此境，则不以平人锢至人；
知有此境，则不以至人限真人；
知有此境，则知医道之极，不在愈病，而在立人；
知有此境，则知华夏之薪，不惟传灯，而在续命。
