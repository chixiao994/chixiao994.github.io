《伤寒卒病论》113方六态解读

凡例

一、本解读依《阴阳周衍体系》，以六态为纲，次第为目，逐态展开。每一态中，先明其本义，次依表里、虚实、寒热之次第推衍其证，然后出方。

二、每一方，皆注明其所属六态、所对治之次第推衍结果，使理法方药一贯贯通。

三、凡仲景原书有方有证者，直接解读。凡按体系推衍应有方而仲景未立条文方药者，以【缺方补遗】标出，依据体系推衍其组方原则，为之拟名，并说明未立之可能缘由。

四、凡一方可通用于多态者，归入其最主要之态，他处互见时注明。

五、本解读所据方剂，以《辑复稿》为准，合113方。

第一部分：太阳态（开态）

本义：阳气向外宣发，卫外为固。开态失常，则阳气被郁于表，玄府闭塞，卫外失司。

表里虚实寒热证候治法方剂
表实寒头项强痛，恶寒，发热，无汗，脉浮紧辛温发汗麻黄汤
表虚寒头痛，发热，汗出，恶风，脉浮缓辛温解肌桂枝汤
表实外寒内热恶寒，发热，无汗，烦躁，脉浮紧辛温发汗，兼清里热大青龙汤
表虚热发热，微恶风寒，汗出，口渴辛凉解表桂枝二越婢一汤

【麻黄汤】 太阳表实寒证

推衍：太阳开态失常 → 玄府闭塞，阳气被郁 → 表实 → 寒邪在表 → 恶寒无汗，脉浮紧，头身疼痛。治当辛温发汗，开腠理，散寒邪。

方药：麻黄三两（去节），桂枝二两（去皮），甘草一两（炙），杏仁七十个（去皮尖）。

方义：麻黄开玄府，为君；桂枝助阳发汗，为臣；杏仁利肺气以助宣散；甘草调和诸药。四药合，一汗而表解。此乃“自回”法之典型：正气未衰，但去其邪，汗出而表气通，阳气自回于密固。

【桂枝汤】 太阳表虚寒证

推衍：太阳开态失常 → 卫气不固，营阴外泄 → 表虚 → 寒邪在表 → 恶风汗出，脉浮缓。治当解肌和营，以发微汗。

方药：桂枝三两（去皮），芍药三两，甘草二两（炙），生姜三两（切），大枣十二枚（擘）。

方义：桂枝解肌发表，为君；芍药敛阴和营，一散一收，使表气和而卫外复固；生姜助桂枝散邪；大枣助芍药益营；甘草调和。啜热稀粥助汗，微汗则解。此为“表中之虚”的治法：虽有表邪，不可峻汗，须和其营卫，扶正以祛邪。

【大青龙汤】 太阳表实外寒内热证

推衍：太阳开态失常 → 玄府闭塞，阳气被郁而化热 → 表实 → 外寒内热 → 恶寒无汗，烦躁。治当发汗散寒，兼清内热。

方药：麻黄六两（去节），桂枝二两（去皮），甘草二两（炙），杏仁四十枚（去皮尖），生姜三两（切），大枣十枚（擘），石膏如鸡子大（碎）。

方义：麻黄汤倍麻黄，大发其汗以散表寒；加石膏清里热以除烦躁。此为太阳兼阳明之证，表里同治。阳证正气尚充，故可表里双解。

【桂枝二越婢一汤】 太阳表虚热证

推衍：太阳开态失常 → 卫气不固，兼有郁热 → 表虚 → 热 → 汗出身热，恶风口渴。治当微发其汗，兼清郁热。

方药：桂枝（去皮），芍药，麻黄，甘草（炙）各十八铢，大枣四枚（擘），生姜一两二铢（切），石膏二十四铢（碎，绵裹）。

方义：以桂枝汤微发汗以和营卫，越婢汤（麻黄、石膏、生姜、大枣、甘草）清郁热。量极小，取其微汗微清，不伤津液。

第二部分：少阳态（枢态）

本义：阳气出入转换，条畅气机，为表里之枢。枢态失常，则气机郁滞，表里不利。

表里虚实寒热证候治法方剂
半表半里不偏寒热往来胸胁苦满，默默不欲食，心烦喜呕，口苦咽干目眩和解少阳，旋转枢机小柴胡汤
半表半里偏实偏热呕不止，心下急，郁郁微烦和解兼通下大柴胡汤
半表半里偏虚偏寒胸胁满微结，小便不利，渴而不呕，但头汗出，心烦和解兼温化柴胡桂枝干姜汤
半表半里兼表寒热发热微恶寒，支节烦疼，微呕，心下支结和解兼解表柴胡桂枝汤

【小柴胡汤】 少阳枢机不利主方

推衍：少阳枢态失常 → 气机郁滞半表半里 → 正邪交争于枢 → 往来寒热，胸胁苦满，口苦咽干目眩。治当旋转枢机，使表里自和。

方药：柴胡半斤，黄芩三两，人参三两，半夏半升（洗），甘草三两（炙），生姜三两（切），大枣十二枚（擘）。

方义：柴胡升散，旋转少阳枢机，为君。黄芩清胆热，半夏降逆止呕，生姜、大枣和胃气，人参、甘草扶正气。全方旋转表里，使枢机自利。仲景于方后注云：“上焦得通，津液得下，胃气因和，身濈然汗出而解。”此即枢机一转，表里气通，邪从表解之明证。故此方虽曰“和”，其治法之方向仍是向外，给邪以出路。

【大柴胡汤】 少阳偏实，兼阳明里实

推衍：少阳枢态失常 → 气机郁滞半表半里 → 偏实 → 偏热，兼阳明里实 → 呕不止，心下急，郁郁微烦。治当和解兼通下。

方药：柴胡半斤，黄芩三两，芍药三两，半夏半升（洗），生姜五两（切），枳实四枚（炙），大枣十二枚（擘），大黄二两。

方义：于小柴胡汤中去人参、甘草之甘补，加枳实、大黄通阳明之实，芍药和营缓急。此为少阳阳明合病之方，表里同治。阳证可合方，此是一例。

【柴胡桂枝干姜汤】 少阳偏虚，兼太阴虚寒

推衍：少阳枢态失常 → 气机郁滞半表半里 → 偏虚 → 偏寒，兼太阴水饮 → 胸胁满微结，小便不利，渴而不呕，但头汗出。治当和解兼温化。

方药：柴胡半斤，桂枝三两（去皮），干姜二两，栝楼根四两，黄芩三两，牡蛎二两（熬），甘草二两（炙）。

方义：柴胡、黄芩和解少阳。桂枝、干姜温太阴之寒，化气利水。栝楼根生津止渴，牡蛎散结。此为少阳兼太阴虚寒之方，和解与温化并行。

【柴胡桂枝汤】 少阳兼太阳表证

推衍：少阳枢态失常 → 气机郁滞半表半里 → 兼太阳表虚 → 发热微恶寒，支节烦疼，微呕，心下支结。治当和解兼解表。

方药：桂枝一两半（去皮），芍药一两半，黄芩一两半，人参一两半，甘草一两（炙），半夏二合半（洗），大枣六枚（擘），生姜一两半（切），柴胡四两。

方义：小柴胡汤与桂枝汤各半，合为一方。柴、芩和解少阳，桂、芍解肌和营。此为太阳少阳合病之方，亦阳证可合方之例。

第三部分：阳明态（合态）

本义：阳气向内收敛，腐熟水谷，传导糟粕。合态失常，则阳气过亢，向内壅聚，燥热结实。

表里虚实寒热证候治法方剂
里实大热大热，大汗，大渴，脉洪大辛寒清热白虎汤
里实热潮热，谵语，腹满痛，大便硬，脉沉实苦寒攻下大承气汤
里实热潮热，谵语，腹胀满，大便硬，未至燥坚轻下小承气汤
里实热心烦，微谵语，腹胀满，大便微硬缓下和胃调胃承气汤
里虚热虚羸少气，气逆欲吐，烦渴清热益气生津竹叶石膏汤

【白虎汤】 阳明经证

推衍：阳明合态失常 → 阳气内壅过亢 → 里实热 → 无形热邪弥漫 → 大热大汗大渴脉洪大。治当辛寒清热，直折其火。

方药：知母六两，石膏一斤（碎），甘草二两（炙），粳米六合。

方义：石膏辛寒清阳明大热，为君；知母苦寒滋阴清热；粳米、甘草和胃护津。四药合用，大清气分之热而不过寒伤胃。此为“自回”法中清法之典型：热清则阳气自敛，阴津自复。

【大承气汤】 阳明腑实证

推衍：阳明合态失常 → 阳气内壅过亢 → 里实热 → 无形热邪与有形燥屎相结 → 痞满燥实，潮热谵语。治当急下存阴。

方药：大黄四两（酒洗），厚朴半斤（炙，去皮），枳实五枚（炙），芒硝三合。

方义：大黄苦寒攻下，芒硝咸寒软坚，厚朴、枳实行气破结。四药合力，釜底抽薪，急下以存将竭之阴。此为“自回”法中下法之峻剂。

【小承气汤】 阳明腑实轻证

推衍：阳明合态失常 → 里实热 → 腑实未至燥坚 → 腹大满，大便硬，微有潮热。治当轻下。

方药：大黄四两（酒洗），厚朴二两（炙，去皮），枳实大者三枚（炙）。

方义：即大承气汤去芒硝，减厚朴、枳实之量。去芒硝则不欲其速下，减枳朴则行气之力稍缓。用于腑实轻证。

【调胃承气汤】 阳明腑实更轻证

推衍：阳明合态失常 → 里实热 → 燥热在胃 → 心烦，微谵语，腹胀满。治当缓下和胃。

方药：大黄四两（清酒洗），甘草二两（炙），芒硝半升。

方义：大黄苦寒攻下，芒硝咸寒润燥，甘草和胃缓中。此方不用枳朴行气，专攻燥热，而力最缓。

【竹叶石膏汤】 阳明余热未清，气阴两伤

推衍：阳明合态失常 → 大病已去，余热未清 → 里虚 → 虚热 → 虚羸少气，气逆欲吐。治当清热益气生津。

方药：竹叶二把，石膏一斤，半夏半升（洗），麦门冬一升（去心），人参二两，甘草二两（炙），粳米半升。

方义：竹叶、石膏清余热，人参、麦冬益气生津，半夏降逆止呕，甘草、粳米和胃。此为热病后期，气阴两伤之调治方。

第四部分：太阴态（化态）

本义：阴气始盛，运化水谷，化生气血。化态失常，则脾阳虚衰，运化无权，水湿内停。

表里虚实寒热证候治法方剂
里虚纯寒腹满而吐，食不下，自利益甚，时腹自痛，口不渴温中健脾理中丸（汤）
里虚虚寒心中悸而烦，虚劳里急，腹中痛温中补虚小建中汤

【理中丸（汤）】 太阴虚寒主方

推衍：太阴化态失常 → 脾阳虚衰，运化无权 → 里虚寒 → 腹满而吐，食不下，自利益甚。治当温中健脾，恢复运化。

方药：人参，干姜，甘草（炙），白术各三两。

方义：干姜温中散寒，为君。人参补气健脾，白术燥湿健脾，甘草和中调和。四药合用，使中焦得温，运化自复。丸则缓，汤则速。此乃“归序”法第一步“安中定化”之主方。胃气存则生，胃气绝则死。此方为一切阴证治疗之根基。

【小建中汤】 太阴虚劳

推衍：太阴化态失常 → 脾阳虚衰，化生不足 → 里虚寒 → 气血两虚 → 心中悸而烦，腹中急痛，虚劳里急。治当温中补虚，和里缓急。

方药：桂枝三两（去皮），甘草二两（炙），大枣十二枚（擘），芍药六两，生姜三两（切），胶饴一升。

方义：即桂枝汤倍芍药加胶饴。胶饴甘温，合甘草、大枣温补中焦，倍芍药以和营缓急，桂枝、生姜辛温助阳。全方以甘味为主，专补中焦之虚。

第五部分：少阴态（本态）

本义：阴气之根本，性命之源。藏精纳气，水火既济。本态失常，则阳气衰微，或阴虚火旺。

表里虚实寒热证候治法方剂
里虚寒但欲寐，脉沉，下利清谷，手足厥冷回阳救逆四逆汤
里虚假热（格阳）下利清谷，手足厥逆，脉微欲绝，身反不恶寒，面赤破阴回阳，通达内外通脉四逆汤
里虚寒下利，脉微，面赤（戴阳）破阴回阳，宣通上下白通汤
里虚寒身体痛，手足寒，骨节痛，背恶寒温经散寒，补益阳气附子汤
里虚水气腹痛，小便不利，四肢沉重疼痛，自下利温阳利水真武汤
里虚热（热化）心中烦，不得卧滋阴清热黄连阿胶汤
里虚水热下利，咳而呕渴，心烦不得眠，小便不利滋阴利水清热猪苓汤

【四逆汤】 少阴虚寒主方

推衍：少阴本态失常 → 心肾阳气衰微 → 里虚寒 → 但欲寐，脉沉，下利清谷，四逆。治当急温其里，回阳救逆。

方药：甘草二两（炙），干姜一两半，附子一枚（生用，去皮，破八片）。

方义：附子大辛大热，回阳救逆，为君。干姜温中散寒，助附子破阴。甘草甘温，和诸药，缓急迫，且能制附子之毒性。三味纯阳之品，直入心肾，点燃将熄之真阳。此乃“归序”法第二步“固本复密”之主方。太阴已立，中焦能运，方可进而温少阴之真阳。

【通脉四逆汤】 少阴格阳证

推衍：少阴本态失常 → 阴盛于内，格阳于外 → 里虚寒 → 下利清谷，手足厥逆，脉微欲绝，身反不恶寒，面赤。此为真寒假热之危候。治当破阴回阳，通达内外。

方药：甘草二两（炙），附子大者一枚（生用，去皮，破八片），干姜三两（强人可四两）。

方义：即四逆汤倍干姜，增附子量。干姜量重，则破阴之力更强；附子量大，则回阳之力更峻。此为阴盛格阳之危证所设。临证须以“真假卷”之六法鉴别，万不可误为热证而用寒凉。

【白通汤】 少阴戴阳证

推衍：少阴本态失常 → 阴盛于下，格阳于上 → 里虚寒 → 下利，脉微，面赤（戴阳）。治当破阴回阳，宣通上下。

方药：葱白四茎，干姜一两，附子一枚（生，去皮，破八片）。

方义：即四逆汤去甘草之缓，加葱白之辛通。葱白宣通上下阳气，合姜附破阴回阳。此方不用甘草，取其速效而不欲缓。面赤为戴阳之候，是假热，不可误作实热。

【附子汤】 少阴阳虚身痛

推衍：少阴本态失常 → 阳气虚衰，经脉失煦 → 里虚寒 → 身体痛，手足寒，骨节痛，背恶寒。治当温经散寒，补益阳气。

方药：附子二枚（炮，去皮，破八片），茯苓三两，人参二两，白术四两，芍药三两。

方义：炮附子温经散寒，人参、白术益气健脾，茯苓利水，芍药和营缓急。此为少阴阳虚兼寒湿之身痛而设。炮附子较生附子力缓，而偏于温经。

【真武汤】 少阴阳虚水泛

推衍：少阴本态失常 → 肾阳衰微，水气内停 → 里虚 → 水气 → 腹痛，小便不利，四肢沉重疼痛，自下利。治当温阳利水。

方药：茯苓三两，芍药三两，白术二两，生姜三两（切），附子一枚（炮，去皮，破八片）。

方义：炮附子温肾阳以化水，为君；白术、茯苓健脾利水；生姜散水气；芍药利小便兼和营。全方温阳而不燥，利水而不伤阴。

【黄连阿胶汤】 少阴虚热证

推衍：少阴本态失常 → 肾水亏虚，心火独亢 → 里虚热 → 心中烦，不得卧。治当滋阴清热，交通心肾。

方药：黄连四两，黄芩二两，芍药二两，鸡子黄二枚，阿胶三两（一云三挺）。

方义：黄连、黄芩清心火，阿胶、鸡子黄滋肾阴，芍药和营。此方滋阴与清热并用，交通心肾，为少阴热化证之正方。此证虽属少阴，而偏于虚热，与四逆汤之纯寒证截然相反。

【猪苓汤】 少阴水热互结

推衍：少阴本态失常 → 阴虚水热互结 → 里虚热兼水 → 下利，咳而呕渴，心烦不得眠，小便不利。治当滋阴利水清热。

方药：猪苓（去皮），茯苓，泽泻，阿胶，滑石（碎）各一两。

方义：猪苓、茯苓、泽泻利水，滑石清热利窍，阿胶滋阴润燥。利水而不伤阴，清热而不苦燥。

推衍：厥阴逆态失常 → 阴阳不顺接 → 上热下寒，寒热错杂 → 消渴，气上撞心，心中疼热，饥而不欲食，食则吐蛔。治当寒热并用，调其阴阳，恢复顺接。

方药：乌梅三百枚，细辛六两，干姜十两，黄连十六两，当归四两，附子六两（炮，去皮），蜀椒四两（出汗），桂枝六两（去皮），人参六两，黄柏六两。

方义：乌梅酸收，为君，敛肝之逆气。黄连、黄柏清上热，干姜、附子、蜀椒、细辛、桂枝温下寒。人参、当归益气养血。全方酸苦辛甘并用，寒热并行，使阴阳复归顺接。此乃“归序”法第三步“调逆复平”之主方。太阴已立、少阴已复，正气已有相当恢复，此时方可处理厥阴之复杂局面。

【当归四逆汤】 厥阴血虚寒凝

推衍：厥阴逆态失常 → 肝血不足，寒凝经脉 → 里虚寒 → 手足厥寒，脉细欲绝。治当温经养血，散寒通脉。

方药：当归三两，桂枝三两（去皮），芍药三两，细辛三两，甘草二两（炙），通草二两，大枣二十五枚（擘）。

方义：当归、芍药养血和营，桂枝、细辛温经散寒，通草通利血脉，大枣、甘草益气和中。此为血虚寒凝之手足厥冷而设。

【当归四逆加吴茱萸生姜汤】 厥阴血虚久寒

推衍：厥阴逆态失常 → 肝血不足，寒凝经脉 → 内有久寒 → 手足厥寒，脉细欲绝，兼有沉寒痼冷。治当温经养血，兼散久寒。

方药：即当归四逆汤加吴茱萸二升，生姜半斤（切）。以水六升，清酒六升和煮。

方义：吴茱萸、生姜大辛大热，直入厥阴肝经，散其沉寒痼冷。清酒煎则温通之力更强。

【白头翁汤】 厥阴热利

推衍：厥阴逆态失常 → 肝热下迫大肠 → 里实热 → 热利下重，渴欲饮水。治当清热燥湿，凉血止利。

方药：白头翁二两，黄柏三两，黄连三两，秦皮三两。

方义：白头翁清肝经血分之热，为君。黄连、黄柏清热燥湿，秦皮涩肠止利。四味苦寒，直清厥阴之热毒。此为厥阴之纯热证，无须分步，可直接清热。

【吴茱萸汤】 厥阴寒逆头痛

推衍：厥阴逆态失常 → 肝寒犯胃，浊阴上逆 → 里虚寒 → 干呕，吐涎沫，头痛（巅顶痛）。治当温肝暖胃，降逆止呕。

方药：吴茱萸一升（洗），人参三两，生姜六两（切），大枣十二枚（擘）。

方义：吴茱萸辛热，直入肝经，温散肝寒，降其逆气，为君。生姜助其降逆，人参、大枣益气和中。此方专治厥阴肝寒上逆之巅顶痛，纯寒无热。

【缺方补遗】

以下为依《阴阳周衍体系》推衍，应有方药而仲景未立条文方药者。按其所属六态与次第推衍，拟出组方原则，并为命名，附说明未立之可能缘由。

【缺方一】太阴化态失常·表证

推衍：太阴为化态，主运化。若太阴中风，脾阳不足，外邪乘虚入于肌表，可见四肢烦疼、恶风、汗出、脉浮弱。此为太阴表虚证。

拟方：太阴桂枝汤。

组方：桂枝、芍药、生姜、大枣、甘草，加人参、白术。

方义：以桂枝汤解肌和营卫，加人参、白术健脾益气，以扶太阴之虚。太阴中风，不可单发其汗，须扶正与解表并行。

仲景未立之由：太阴篇第四条云“太阴病，脉浮者，可发汗，宜桂枝汤”，已示其法，但未单独立方，以桂枝汤为太阳正方，此处借用，故不另立。

【缺方二】少阴本态失常·血虚证

推衍：少阴为水火之脏。若肾水亏虚，肝血不足，可见头晕目眩、面色无华、心悸失眠、脉细弱。此为少阴血虚证。

拟方：地芍阿胶汤。

组方：熟地、白芍、当归、阿胶、茯苓、甘草。

方义：熟地、阿胶填补肾精，当归、白芍养血和肝，茯苓、甘草健脾以助生化。

仲景未立之由：少阴热化证已有黄连阿胶汤，偏于阴虚火旺。此为纯血虚而无热者，仲景未立，盖以《金匮》虚劳篇有之，而《伤寒》以救阳为急，故未备。

【缺方三】厥阴逆态失常·气滞证

推衍：厥阴主疏泄。若气机郁滞，肝失条达，可见胸胁胀痛、善太息、情志抑郁、脉弦。此为厥阴气滞证。

拟方：疏肝解郁汤。

组方：柴胡、枳壳、白芍、甘草、香附、川芎。

方义：柴胡疏肝解郁，枳壳行气宽中，白芍柔肝缓急，香附、川芎调气和血，甘草调和。

仲景未立之由：小柴胡汤治少阳枢机，四逆散治少阴四逆，均有疏肝之意。厥阴气滞纯证，仲景未专立方，以柴胡类方已可通用。

【缺方四】厥阴逆态失常·血瘀证

推衍：厥阴肝经藏血。若肝血瘀滞，可见胁下刺痛、痛有定处、舌紫暗、脉涩。此为厥阴血瘀证。

拟方：红蓝花散。

组方：红蓝花、当归、赤芍、桃仁、柴胡、甘草。

方义：红蓝花活血化瘀，当归、赤芍养血活血，桃仁破瘀，柴胡引经入肝，甘草调和。

仲景未立之由：抵当汤、桃核承气汤治下焦瘀热，在太阳篇。肝经血瘀之纯证，仲景未立，《金匮》虚劳篇大黄蛰虫丸可参。

结语

《阴阳周衍体系》起于总论，终于此附论之方解。十卷既成，理法方药一贯贯通。

卷一总论立体系之根基，明“阴平阳密”为平人之准。
卷二阴阳辨病之总纲，判阳病与阴病。
卷三六态以六态为纲，统摄万病。
卷四表里、卷五虚实、卷六寒热为次第推衍，层层深入。
卷七次第总结四步推导之逻辑。
卷八真假破假象，见真机。
卷九自回、卷十归序明阴阳治法之大判。

今附此方解，将仲景113方各归其态，各明其理。凡有方者，依体系推衍其证，使知何态何次第而有此方；凡缺方者，依体系推衍其法，使知何处可补何方。

执此一册，则《伤寒卒病论》之全体大用，皆在掌握之中。理也，法也，方也，药也，一以贯之。
