序言：三体论

古籍的存在形态，可归纳为三个层次：实体（物理存在）、虚体（认知存在）、拟体（数字存在）。三者各有其源、各有其层、各有其用。本理论以“版面”为原点，以“层”为结构，以“缀合”为方法，旨在为古籍的传承、研究与数字化提供一套自洽、无歧义的核心定义。

第一章 基础概念

1.1 三体本源

“古籍的实体，来自于雕版，古籍的拟体，来自于扫描和模拟重排，古籍的虚体，来自于意念。”

  • 实体：物理载体，源于雕版印刷。
  • 拟体：数字载体，源于扫描或模拟排印。
  • 虚体：认知载体，源于人的意念与意象连缀。

1.2 层次划分

“实体版面有两个层次，第一层是雕和印，第二层是订，这两层版面会发生极大变化，后续所有可能混乱的命名正来在于此。”

“我们首先要正名，就是要明确处于什么层次，我们称为印面和订面。”

  • 第一层（雕印层）：印面——雕版印刷的原初版面。
  • 第二层（订层）：订面——装订后形成的物理单面。

“拟体的版面同样有两个层次，第一个是直接扫描自印面，第二个是直接扫描自订面，模拟排印就是模拟的这两个次层。”

  • 拟体第一层：直接扫描自印面的拟面。
  • 拟体第二层：直接扫描自订面的拟面。
  • 模拟排印：在数字空间中模拟这两个层次的形成过程。

第二章 实体层——物理存在

2.1 版框与内容

“版框是古籍的第一载体约束，文字是古籍的内容，一个自然完整印面有完整的版框和完整的内容，一个完整的订面有两个不完整版框和各自填充的内容。”

  • 版框：第一载体约束，定义版面空间边界。
  • 内容：版框内的文字。
  • 印面：完整版框 + 完整内容。
  • 订面：两个不完整版框 + 各自内容。

2.2 常规范围

“古籍的常规版式是版框约束，经折装、旋风装、白纸手抄、字画等不属于常规古籍。”

  • 常规古籍以版框为界定标准。
  • 非常规形态（经折装、旋风装、手抄、字画）暂不纳入本理论范畴。

2.3 核心定位

“中缝一词不再使用，对印面，我们用印刷中心，对于订面我们用装订位置。”

  • 印刷中心：印面的结构中心区域（传统“版心”）。
  • 装订位置：订面的物理折叠、固定位置。

2.4 实面体系

“一个实面，包括一个完整版框或两个半版框内容面，我们称为一个实面。”

  • 实面：物理单元的总称。

“一个印面只有一种形式，就是整实面，一个订面有两种形式，蝴蝶装是整实面，锁线装是合实面。”

  • 整实面：包含一个完整版框的物理单元。
    • 印面是整实面。
    • 蝴蝶装翻开的一面是整实面。
    • 锁线装一叶的正反面构成整实面。
  • 合实面：由两个半实面拼接而成的物理单元。
    • 锁线装摊开时，来自两个不同整实面的半实面视觉拼接。

“合实面包括两个半实面，合拟面包括两个半拟面，合实面不是整实面，合拟面不是整拟面，不同整实面的半面组合称为合实面，不同拟面的半面组合称为合拟面。”

  • 半实面：包含半个版框的物理局部。
  • 合实面的条件：必须来自不同整实面的半面组合。

“合实面只能来自两个不同的版框内容实面，合拟面只能来自两个不同的版框内容的拟面。”

  • 合实面的本质是异源拼接。

“锁线装来自正反面的两半构成的是整实面，蝴蝶装翻开一面是整实面。”

  • 锁线装的一叶（正反两面）在物理上是一张纸，属于整实面。
  • 蝴蝶装翻开后显示的完整版框，属于整实面。

“半面的主要用途在于阅读和操作。”

  • 半面（半实面/半拟面）的定位：操作单元，服务于阅读和数字化处理。

“整实面的装订实体或类整实面的合拟面的装订实体，作为我们的研究对象，其它不具有典型性不作为研究对象。”

  • 研究对象：
    • 整实面的装订实体（原生）。
    • 类整实面的合拟面的装订实体（再生）。
  • 非研究对象：非整实面的装订实体（如合实面直接装订）。

2.5 扫描模式

“一般而言，古籍会有两种扫描模式，只扫半实面（只拍半边），扫一个来自不同版框内容的合实面（直接把书翻开两边一起拍进去，这个是占据绝对主导地位的，少有人会用手机一页页拍），极少出现扫一个整实面（蝴蝶装很少，拆散锁线装扫描显然不可取）。”

  • 主流扫描模式：合实面扫描（翻开书，左右两页一起拍）。
  • 次要模式：半实面扫描（单页拍）。
  • 罕见模式：整实面扫描（拆书或蝴蝶装）。

第三章 拟体层——数字存在

3.1 拟体本源

“对于拟体，它虽然继承自印面或订面，但由于载体发生明显变迁，描述不能直接迁移，这是命名混乱的第二个源头。”

  • 拟体继承自实体，但载体已从纸张变为像素。
  • 物理描述不可直接迁移，需要建立独立的拟体描述体系。

3.2 拟面体系

“拟面也有两种典型模式，包括一个完整版框和内容面的我们称为整拟面，包括两个半版框的我们称为合拟面。”

  • 整拟面：包含一个完整版框内容的数字拟面。
  • 合拟面：包含两个半版框的数字拟面。

“合实面包括两个半实面，合拟面包括两个半拟面，合实面不是整实面，合拟面不是整拟面，不同整实面的半面组合称为合实面，不同拟面的半面组合称为合拟面。”

  • 半拟面：包含半个版框的数字拟面。
  • 合拟面的条件：必须来自不同拟面的半面组合。

“合拟面只能来自两个不同的版框内容的拟面。”

  • 合拟面是异源拼接的数字拟面。

3.3 拟面处理

“拟面处理通常有两种模式，一是剔除背景翻页口堆层或其他干扰，还原成半拟面；二是通过一定的手段得到整拟面，如裁切、拼补、平移、旋转、缩放、虚排等。”

  • 模式一（还原）：从合拟面或带干扰的拟面中，提取干净的半拟面。
  • 模式二（重构）：通过数字操作，将半拟面组合或重构为整拟面。

“半拟面的处理手段，通常有裁切、变形、旋转、调色、挖补。”

  • 裁切：去除背景干扰。
  • 变形：校正几何畸变。
  • 旋转：调整方向。
  • 调色：统一色调，增强清晰度。
  • 挖补：修复破损、污渍。

3.4 拟面用途

“半拟面的主要用途是用于手机阅读和操作形成整拟面，整拟面的主要用途是用于虚拟出版（古籍传承）。”

  • 半拟面：手机阅读 + 操作单元（为形成整拟面服务）。
  • 整拟面：虚拟出版 + 古籍传承。

3.5 拟体生实体

“对于古籍传承的出版实体，它既可以完全由整实面装订而成，也可以由整拟面打印成整实面装订而成。”

  • 传承实体的两种来源：
    • 原生整实面装订。
    • 整拟面打印成整实面再装订。

“非整实面的装订实体，不作为我们的研究对象，因为它不具有典型性。”

  • 排除非整实面的装订形态（合实面装订等）。但类整实面的合拟面的装订实体属于研究对象。

第四章 虚实相缀——结构的层叠与递归

4.1 缀合原理

“实体是由整实面与合实面相缀而成，是个整实面是一个版框内容，当版框装了文字，它必然与下一面不同，上一面与下一面各分一半在一个视觉单元上拼接（锁线装）或者在一个物理实体上拼接（真正的蝴蝶装要求两张纸各一半完全背对背严丝合缝的粘成一体，在精美图册、儿童读物中最常见），两个实面不会必然形成一本书，而是依赖于合实面的存在。”

  • 整实面提供内容，合实面提供连接。
  • 合实面有两种形式：
    • 锁线装：视觉拼接（两个不同整实面的半面在视觉上拼合成一个单元）。
    • 真正蝴蝶装：物理拼接（两张纸各一半全幅粘合）。

“锁线装的定义是绝对自洽的，当来自两个不同整实面的半实面，模拟成一个整实面时，它就是锁线装摊平时的状态，它只是视觉上拼接，所以是合实面，他们不是来自同一个版框。”

  • 锁线装摊开时，左右两页来自不同整实面的半面。
  • 视觉上拼接成“整”，但本质是合实面。

“蝴蝶装就是真正的蝴蝶装，一切只是点粘书脊的推论都是错误的，是来自于对古人的不尊重，也是不符合常理和阅读翻页顺序的，古人纳鞋都知道浆糊要一层层粘满，订书难道蠢到不全部粘满吗？”

  • 真正蝴蝶装：两张纸各半，背对背全幅粘合。
  • 点粘书脊是错误推论。

4.2 册的层级

“所以整实面与合实面相缀而成实体。实体以册为形，而度某书以几册论之。”

  • 实体：由整实面与合实面相缀而成。
  • 册：实体的外在形态，是古籍的计量单位。

“而册册之间以虚实面缀之，此虚实面是物理之虚面，由此而观之，整实面与合实面相缀而成实体，实体与虚体相缀而成更大的实体。而再观扫描或虚拟排印之拟面，是它能再次印制成实面的根本所在。”

  • 册与册的连接：通过虚体（物理虚面）缀合。
  • 宏观结构：实面缀成册，册与册缀成更大的实体。
  • 拟体的价值：可逆性——拟面可以再次印制为实面。

4.3 虚体的意象化

“虚体是意象化，为什么一本书有几册时写了第一册第二册第三册，就会自然连缀，这不是他们真的订在一起，而是靠虚体连接成更大的实体。”

  • 虚体：认知中的意象连缀，而非物理连接。
  • 编号（第一册、第二册）是虚体的表现形式。

“书册形成了一个实体，无数同版实体构成一个更大的实体，所有版本又形成更大的实体。扫描这一动作，恰好就是意象化的具现，想复制实体于是就发明和利用工具把它具现出来，这儿更深一层的意思是一本书不只有册与册的关系，还有本体与无数个相同本体构成更大本体的关系。”

  • 层级扩展：册 → 书 → 同版集合 → 所有版本集合。
  • 扫描：意象化具现的手段——将复制意象转化为数字实体。
  • 本体：原初形态；相同本体：通过复制产生的副本。二者共同构成“更大的本体”。

“实体由无数个相似同体通过意象这个虚体连缀构成，其中的个体一般可以由几本相贯的子实体通过子虚体连缀而成，也就是整实面与合实面成实体，实体与虚体形成新实体，新实体与新虚体构成新新实体，以至于无穷，想缀到哪层就到哪层。”

  • 递归原则：实体 + 虚体 = 新实体，可无限递归。
  • 层级控制：想缀到哪层就到哪层，取决于研究目标。

4.4 虚体的表现形式

“虚体一般表现为卷、册、典、版等形式。”

  • 卷：内容或逻辑划分单位。
  • 册：物理聚集单位。
  • 典：文化或目录学单位。
  • 版：版本概念。

“这儿的版虽然指版本，但它与版框内容是同构的，为什么？因为只有相同版框构内容建成的实体才能称为一版。”

  • 版本与版框同构。
  • 版框一致 = 版本一致。
  • 版框是版本的可视化“指纹”。

第五章 拟体组织与操作

5.1 拟体的文档化

“拟体同样遵循拟面到拟体再到更大拟体的过程，但又不完全相同。在实际应用中，拟面多以半拟面与人交互，半拟面之间顺序相连成文档，以阅读器展现，而文档一般以pdf图像形式或纯文字无约束形式，但后者在古籍传承中不是典型，包括到今天也不是依靠点校本传承古籍，因为它信息失真太多。”

  • 拟体的交互单位：半拟面。
  • 文档：半拟面顺序相连形成（如PDF）。
  • 非典型形式：纯文字（点校本），信息失真大，不适用于古籍传承。

“拟体的主要存在形式为文档（单张图片未连成文档也不典型，因为阅读性差），而文档通过文件名的排列形成更大拟体，更可以通过文件夹名的排列形成更更大拟体。”

  • 最小存在形式：文档（PDF/多页图像文件）。
  • 更大拟体：文档通过文件名排序聚合。
  • 更更大拟体：文件夹通过文件夹名排序聚合。

5.2 拟面的合成原则

“半拟面虽是操作单元，但我们如果意图介入拟体生实体，则必须根据装订形式形成合拟面或整拟面。”

  • 半拟面是操作单元，但拟体生实体必须形成整拟面或合拟面。

“实面的合，往往是邻近的合，而半拟面的合，则是取决于欲成实体的模样，比如多叠小册锁线精装，此时的合是首尾合，而如果是直接双面打印钉书钉钉起来的合是依次的合，还有各种模式，都以欲成实体反推而定。”

  • 实体合：物理限制——邻近的合。
  • 拟体合：数字自由——欲成实体反推而定。

5.3 类蝴蝶装的优化

“同样的，生产锁线装是当前古籍普遍的复制形式，但我认为锁线装是用户体验的倒退（不能摊平、视觉割裂、前后跳跃），而类蝴蝶装才是真正符合用户体验的，可以摊平，视觉完整，前后相贯。”

  • 锁线装缺陷：不能摊平、视觉割裂、前后跳跃。
  • 类蝴蝶装优势：可摊平、视觉完整、前后相贯。

“类蝴蝶装不是通过粘胶实现，而是锁线精装的方式，把不同半拟面拼接，用打小册子的方式，锁线精装并不是什么高深技术，而是无数个小册子的组合，最后加个包背。”

  • 类蝴蝶装机制：分册锁线精装 + 包背拼接。
  • 不是粘胶蝴蝶装，而是分册锁线组合。

“现代常见的字典词典等大部头书籍就是采用此方式，当然也适用于普通书籍，比如很多稍微上点档次的小说出版、需要反复翻阅的资料等。”

  • 类蝴蝶装已被现代出版广泛验证，技术成熟。

5.4 拟刻：从半拟面到拟面

“从半拟面到拟体的过程，这是具有一定挑战性的。半拟面前面已经定义过了，它的操作有裁切、旋转、缩放、变形、调色、挖补。拟面的操作有拼合、旋转、缩放、变形、调色、挖补、拟刻。我们更进一步，对拟刻做详细定义，拟刻形式有二，一是完全复制掩模，二是借用它本以显形。”

  • 半拟面操作：裁切、旋转、缩放、变形、调色、挖补。
  • 拟面操作：拼合、旋转、缩放、变形、调色、挖补、拟刻。
  • 拟刻两种形式：
    • 影本：完全复制掩模。
    • 排本：借用它本以显形。

“第一种是影本，第二种是排本。”

  • 影本：核心传承路径，忠实复刻原版框与内容。
  • 排本：非典型传承路径，借它本补全。

“排本也是古籍传承中的非典型形制（字体的参差、文字的疏忽、版式的不美观），影本是整个古籍传承的核心路线。”

  • 影本：核心，追求“与原版一致”。
  • 排本：辅助，用于残损补全，但非主流。

5.5 传承的悖论

“这儿有个很有意思的现象，后人不断推出某某绝对精校版，并且惊为天人，但是往往湮灭于时间的长河中，而那些不试图替代经典的默默无闻的雕刻本复影本，往往得以流传。”

  • 精校版：试图替代经典 → 湮灭。
  • 复影本：不替代经典，只忠实呈现 → 流传。
  • 传承本质：不是“改进”，而是“延续”。

第六章 拟体的终极优势

“作为拟体，它天然具有的优势是可以图文并存，底图与透明文字层的共一，既可阅也可查。”

  • 底图层：原版视觉信息（影本）——可阅。
  • 透明文字层：可检索、可交互文本——可查。
  • 图文并存：形智兼备，优于纯图像或纯文本。

第七章 书籍的放射——从读到变

“一本书它不单单只是一本书，如果是这样世界可能真的只有一本书，书是可以被推向更大的实体的，而它内蕴的每个能力释放出来就形成以它为中心的丰富多彩的世界，从读传刻用到变思新物。”

  • 书的放射：从“读”（阅读）到“传”（保存）到“刻”（复刻）到“用”（应用），再到“变”（变形）到“思”（思考）到“新物”（创造）。
  • 一本书可辐射出一个以它为中心的知识世界。

“当书版中的字被一个个雕刻或拟刻出来，这本书就成了演书的道场。”

  • 演书的道场：当书版中的字被（拟）雕刻出来，这本书便成为认知与创造的空间。

第八章 天朗——天地复位

“当我们出面对一个极为具体的运用，切除翻页堆叠边缘时，层叠区域是在印刷中心，按理说印刷中心在中间怎么会形成层叠，这恰好是锁线装这个傻逼发明，把原本在内的印刷中心硬生生干到了外，这就是倒反天罡天地易位，于是天的刚健变成了天地否，他被污染了，与无数的印刷中心杂合成了浊天，而我们的目标就是让天朗，还世界以本原。”

  • 锁线装的本质：倒反天罡，天地易位。
  • 浊天：印刷中心被外折，与无数页堆叠杂合，被污染。
  • 天朗：从浊天中提取纯净印刷中心，让天朗朗，还世界以本原。

“此时不需要判断左右，哪儿有层叠就切哪儿，层叠必然是印刷中心，从层叠看图，会发现离层叠很远的另一侧是原始的版框竖线，对整体对比度进行增加，深黑堆叠块即为需切除的堆叠，也可以重构出完整版框面从而更容易寻找到印刷中心。”

  • 天朗操作的核心法则：
    • 不判断左右：层叠位置 = 印刷中心位置。
    • 对侧识别：远离层叠的另一侧是原始版框竖线。
    • 对比增强：突出深黑堆叠块，即为需切除的层叠。
    • 重构完整版框：更容易定位印刷中心。

总结：三体缀合，万变归宗

本理论体系以实体、拟体、虚体三体为基础，以印面、订面、实面、拟面、半面为单元，以版框为约束，以缀合为方法，以影本为核心，以天朗为手段，建立起一套从物理到认知再到数字的完整递归框架。

其核心要义可概括为：

版框是版本的指纹，影本是传承的基石，天朗是复位的手段，虚体是连缀的纽带。

实体不可拆，拟体可反复，虚体可无穷。

一本书不被读到老，而是被演到道。
